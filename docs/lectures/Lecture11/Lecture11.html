1 Introduction to Linear Regression

1.1 Why Linear Regression Matters

Linear regression is one of the most fundamental and widely used statistical techniques in data analytics. Healthcare managers will frequently encounter situations where understanding relationships between variables is crucial for decision-making:

  • Resource allocation: How does nurse staffing level affect patient outcomes?
  • Cost management: What factors drive hospital readmission costs?
  • Quality improvement: How does patient wait time impact satisfaction scores?
  • Performance prediction: Can we predict length of stay based on patient characteristics?

Linear regression provides a powerful framework to:

  1. Quantify relationships between variables (e.g., “For every additional nurse per patient, satisfaction increases by X points”)
  2. Test hypotheses about whether relationships are statistically significant
  3. Make predictions about future outcomes
  4. Control for confounding variables when examining effects of interest

1.2 Overview of Linear Regression Types

Type Number of Predictors Example
Simple Linear Regression 1 Patient age → Length of stay
Multiple Linear Regression 2+ Patient age + Severity + Insurance → Length of stay

1.3 Key Concepts and Terminology

Before we dive in, let’s establish key terminology:

  • Dependent Variable (DV): The outcome we want to predict or explain (also called response variable or Y)
  • Independent Variable (IV): The predictor(s) we use to explain the outcome (also called predictor variable or X)
  • Regression Coefficient (β): The slope that quantifies the relationship between an IV and the DV
  • Intercept (α or β₀): The predicted value of Y when all X variables equal zero
  • Residual (ε): The difference between observed and predicted values

2 Simple Linear Regression

2.1 What is it?

Simple linear regression models the relationship between one independent variable (X) and one dependent variable (Y) using a linear model (straight line). It is the foundation for understanding more complex regression models and allows us to quantify how changes in one variable are associated with changes in another.

2.2 When to Use It

Use simple linear regression when you want to:

  • Examine the relationship between two continuous variables
  • Predict an outcome based on a single predictor
  • Quantify the strength and direction of a linear relationship
  • Test whether a relationship is statistically significant

2.3 The Concept

Simple linear regression finds the “best-fitting” line through the data points using a method called Ordinary Least Squares (OLS).

2.3.1 The Model Equation

The simple linear regression model is expressed as:

\[Y_i = \beta_0 + \beta_1 X_i + \epsilon_i\]

Where:

  • \(Y_i\) = Observed value of the dependent variable for observation \(i\)
  • \(\beta_0\) = Intercept (the value of Y when X = 0)
  • \(\beta_1\) = Slope (the change in Y for a one-unit increase in X)
  • \(X_i\) = Value of the independent variable for observation \(i\)
  • \(\epsilon_i\) = Residual for observation \(i\)

2.3.2 Understanding the Components

The Intercept (β₀): The intercept represents the predicted value of Y when X equals zero. In healthcare contexts, this may or may not have a meaningful interpretation. For example, if X is “years of nursing experience,” an intercept would represent the predicted outcome for a nurse with zero years of experience.

The Slope (β₁): The slope is the key parameter of interest. It tells us:

  • Direction: Positive slope = positive relationship; Negative slope = negative relationship
  • Magnitude: How much Y changes for each one-unit increase in X
  • Statistical significance: Whether the relationship is likely to exist in the population (not just due to chance)

2.4 The Ordinary Least Squares (OLS) Method

2.4.1 How OLS Works

Linear regression finds the “best” line by minimizing the sum of squared residuals (SSR):

\[SSR = \sum_{i=1}^{n} (Y_i - \hat{Y}_i)^2 = \sum_{i=1}^{n} \epsilon_i^2\]

Where \(\hat{Y}_i\) is the predicted value for observation \(i\).

Why squared residuals?

  1. Squaring ensures positive and negative errors don’t cancel out
  2. Squaring penalizes larger errors more heavily
  3. Leads to closed-form mathematical solutions

2.4.2 Visual Intuition

2.5 Using the Fitted Model for Predictions

Once OLS finds the best-fitting line by estimating \(\beta_0\) (intercept) and \(\beta_1\) (slope), we can use the fitted model to make predictions for new observations.

The prediction equation is:

\[\hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X\]

Where:

  • \(\hat{Y}\) = Predicted value of the dependent variable
  • \(\hat{\beta}_0\) = Estimated intercept from the fitted model
  • \(\hat{\beta}_1\) = Estimated slope from the fitted model
  • \(X\) = Value of the independent variable for which we want to make a prediction

Key insight: The “hat” notation (^) indicates these are estimated values from our sample data, not the true population parameters. We use the estimated coefficients to predict outcomes for:

  1. Observations within our dataset - to assess model fit
  2. New observations - to forecast outcomes based on predictor values
  3. Hypothetical scenarios - to evaluate “what if” questions (e.g., “What if we reduce wait time to 30 minutes?”)

Let’s see this in action with a real healthcare example.

2.6 Example Case: Patient Satisfaction and Wait Time

2.6.1 Background and Context

Research has consistently shown that emergency department wait times are negatively associated with patient satisfaction. A 2021 study found that being informed about waiting time showed a moderately strong positive correlation with patients’ overall rating, highlighting the importance of wait time management for patient experience.

Let’s examine whether emergency department wait time affects patient satisfaction scores using synthetic data that mirrors these real-world relationships.

2.6.5 The Fitted Regression Equation

Based on the model output above, we can write our fitted regression equation with the estimated coefficients:

\[\widehat{\text{Satisfaction}} = 84.3 + (-0.384) \times \text{Wait Time}\]

Or more generally:

\[\hat{Y}_i = 84.3 + (-0.384) \times X_i\]

Where:

  • \(\hat{Y}_i\) = Predicted patient satisfaction score for patient \(i\)
  • \(X_i\) = Wait time in minutes for patient \(i\)
  • 84.3 = Estimated intercept (\(\hat{\beta}_0\))
  • -0.384 = Estimated slope (\(\hat{\beta}_1\))

This equation allows us to predict patient satisfaction for any given wait time. For example:

  • If wait time = 30 minutes: \(\hat{Y} = 84.3 + (-0.384) \times 30 = 72.8\)
  • If wait time = 60 minutes: \(\hat{Y} = 84.3 + (-0.384) \times 60 = 61.3\)

2.6.6 Interpreting the Results

Let’s break down the output systematically:

2.6.6.1 1. The Intercept

Value: β₀ = 84.3

Interpretation: When wait time is 0 minutes, the predicted patient satisfaction score is 84.3 points. This represents the baseline satisfaction when there is no wait.

2.6.6.2 2. The Slope (Regression Coefficient)

Value: β₁ = -0.384

Interpretation (The Three Key Questions):

  1. Direction: The coefficient is negative (-0.384), indicating that longer wait times are associated with lower satisfaction scores.

  2. Magnitude: For every one-minute increase in wait time, patient satisfaction decreases by 0.384 points on the 0-100 scale.

  3. Statistical Significance: The p-value is 1.824779e-22, which is less than 0.05. We reject the null hypothesis that there is no relationship between wait time and satisfaction. The relationship is statistically significant.

2.6.6.3 3. Model Fit (R-squared)

R² = 0.475

Interpretation: Wait time explains 47.5% of the variance in patient satisfaction scores. The remaining 52.5% is explained by other factors not included in this model (e.g., staff friendliness, treatment effectiveness, facility cleanliness).

2.6.6.4 Visualizing R-squared: Explained vs. Unexplained Variance

To understand R² visually, let’s see how the regression model reduces prediction error compared to simply using the mean:

# Calculate variance components
ed_data_variance <- ed_data %>%
  mutate(
    predicted = predict(model_simple),
    mean_y = mean(satisfaction_score),
    # Total variance: deviation from mean
    total_dev = satisfaction_score - mean_y,
    # Explained variance: deviation of prediction from mean
    explained_dev = predicted - mean_y,
    # Residual variance: deviation from prediction
    residual_dev = satisfaction_score - predicted
  )

# Calculate sums of squares
TSS <- sum(ed_data_variance$total_dev^2)
ESS <- sum(ed_data_variance$explained_dev^2)
RSS <- sum(ed_data_variance$residual_dev^2)
R2 <- ESS / TSS

3 Multiple Linear Regression

3.1 What is it?

Multiple linear regression extends simple regression to model the relationship between multiple independent variables and one dependent variable. It allows us to examine how several predictors simultaneously influence an outcome.

3.2 When to Use It

Use multiple linear regression when you need to:

  • Include multiple predictors to better explain variance in an outcome
  • Control for confounding variables when examining specific relationships
  • Compare the relative importance of different factors
  • Make predictions based on multiple characteristics simultaneously

3.3 Extending to Multiple Predictors

In reality, outcomes of interest are influenced by many factors simultaneously. Multiple linear regression allows us to account for this complexity.

3.3.1 The Model Equation

\[Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \cdots + \beta_k X_{ki} + \epsilon_i\]

Where:

  • \(\beta_0\) = Intercept
  • \(\beta_1, \beta_2, \ldots, \beta_k\) = Regression coefficients for each predictor
  • \(X_{1i}, X_{2i}, \ldots, X_{ki}\) = Values of predictors for observation \(i\)
  • \(\epsilon_i\) = Residual

In multiple regression, each coefficient represents the effect of that variable holding all other variables constant (also called the “partial” or “conditional” effect).

3.4 An Example Case: Hospital Length of Stay

3.4.1 Background and Context

A 2023 systematic review identified age, comorbidities, and severity as the most frequently cited predictors of hospital length of stay across 15 studies. Understanding these factors is crucial for healthcare operations and resource planning.

Let’s predict hospital length of stay (LOS) based on three key patient characteristics using synthetic data that reflects these evidence-based relationships:

  1. Age - Patient age in years
  2. Severity Score - Illness severity on a 1-10 scale
  3. Number of Comorbidities - Count of concurrent chronic conditions

3.4.2 Creating Comprehensive Healthcare Data

Let’s create a dataset using the code below.

# Generate synthetic hospital data
n <- 300

hospital_data <- tibble(
  patient_id = 1:n,
  age = round(rnorm(n, mean = 55, sd = 18)),
  severity_score = round(runif(n, 1, 10), 1),  # 1-10 scale
  num_comorbidities = rpois(n, lambda = 2)
) %>%
  mutate(
    # Ensure realistic age bounds
    age = pmax(18, pmin(age, 95)),
    # Generate LOS based on predictors
    length_of_stay = round(
      1.5 +                          # Base stay
      0.04 * age +                   # Age effect
      0.6 * severity_score +         # Severity effect
      0.8 * num_comorbidities +      # Comorbidity effect
      rnorm(n, 0, 1.5),              # Random error
      1
    ),
    # Ensure positive LOS
    length_of_stay = pmax(1, length_of_stay)
  )

# Summary statistics
hospital_data %>%
  select(age, severity_score, num_comorbidities, length_of_stay) %>%
  summary()

Each coefficient represents the effect of that variable while holding all other variables constant.

  4. Number of Comorbidities (β₃ = 0.754): Holding age and severity constant, each additional comorbidity is associated with a 0.75-day increase in length of stay.

3.4.6.1 Manual Calculation Example

Let’s manually calculate one prediction to understand how multiple regression works. We’ll predict LOS for the “Elderly, Moderate” patient (Age = 75, Severity = 5, Comorbidities = 2; the second new patient in the table above).

Step 1: Write the fitted regression equation

First, recall our fitted model equation with estimated coefficients:

\[\widehat{\text{LOS}} = 1.66 + 0.039 \times \text{Age} + 0.592 \times \text{Severity} + 0.754 \times \text{Comorbidities}\]

Or in general notation:

\[\hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X_1 + \hat{\beta}_2 X_2 + \hat{\beta}_3 X_3\]

Where:

  • \(\hat{Y}\) = Predicted length of stay
  • \(X_1\) = Age (years)
  • \(X_2\) = Severity score (1-10)
  • \(X_3\) = Number of comorbidities
  • \(\hat{\beta}_0\) = 1.66 (Intercept)
  • \(\hat{\beta}_1\) = 0.039 (Age coefficient)
  • \(\hat{\beta}_2\) = 0.592 (Severity coefficient)
  • \(\hat{\beta}_3\) = 0.754 (Comorbidity coefficient)

Step 2: Substitute the patient’s values

For the “Elderly, Moderate” patient:

  • Age = 75 years
  • Severity = 5
  • Comorbidities = 2

\[\widehat{\text{LOS}} = 1.66 + 0.039 \times 75 + 0.592 \times 5 + 0.754 \times 2\]

Step 3: Calculate step-by-step

Step-by-step calculation:
Intercept:               1.66 
Age effect:              0.039 × 75 = 2.96 
Severity effect:         0.592 × 5 = 2.96 
Comorbidity effect:      0.754 × 2 = 1.51 
                         ---------------------------------------- 
Predicted LOS:           9.09 days

Result: The predicted length of stay for a 75-year-old patient with severity score of 5 and 2 comorbidities is 9.09 days.

You can verify this matches the value in the prediction table above for the “Elderly, Moderate” patient!

In multiple regression, each predictor contributes to the final prediction. We simply add up all the effects (intercept + age effect + severity effect + comorbidity effect) to get the total predicted outcome.

4 Model Assumptions and Diagnostics

4.1 Key Assumptions of Linear Regression

Linear regression relies on several assumptions. Understanding these assumptions helps ensure valid statistical inference and reliable predictions.

4.1.1 1. Linearity:

  • The relationship between predictor(s) and outcome is linear.
  • If the true relationship is curved but we fit a straight line, predictions will be systematically biased.
  • We can visually check by drawing a scatterplot
  • If violated: Consider transforming variables (log, square root) or using polynomial terms.

4.1.2 2. Independence of Observations

  • Each observation’s residual is unrelated to others’ residuals.
  • Correlated errors (e.g., repeated measures, clustered data) underestimate standard errors, making p-values too small.
  • Know your data structure (longitudinal? clustered?)
  • If violated: Use mixed models, clustered standard errors, or time-series methods.

4.1.3 3. Homoscedasticity (Equal Variance)

  • Variance of residuals is constant across all fitted values.
  • Unequal variance (heteroscedasticity) makes standard errors unreliable and confidence intervals inaccurate.
  • We can visually inspect by drawing a Residuals vs Fitted plot (vertical spread should be roughly equal across x-axis)
  • If violated: Use weighted least squares or robust standard errors; consider transforming Y.

4.1.4 4. Normality of Residuals

  • Residuals follow a normal distribution.
  • Critical for valid p-values and confidence intervals
  • We can visually inspect using Q-Q plot (points should follow diagonal line)
  • If violated: Consider transforming Y or using robust methods.

4.1.5 5. No (Perfect) Multicollinearity (Multiple Regression Only)

  • Predictors are not highly correlated with each other.
  • High correlation between predictors inflates standard errors, making coefficients unstable and hard to interpret.
  • We can check this visually (with correlation matrix) and check Variance Inflation Factor (VIF; VIF > 10 indicates problematic multicollinearity)
  • If violated: Remove redundant predictors, combine correlated predictors, or use penalized regression (we will cover this later in the semester).

4.1.6 Summary: Which Plot Checks Which Assumption?

Assumption Primary Diagnostic
Linearity Residuals vs Fitted (look for no pattern)
Independence Know your study design
Homoscedasticity Residuals vs Fitted (equal vertical spread)
Normality Q-Q plot

4.2.1 Interpreting the Two Standard Diagnostic Plots

Plot 1: Residuals vs Fitted

  • What to look for: Random scatter around horizontal line at 0
  • What it checks: Linearity and homoscedasticity
  • Good sign: No pattern, equal spread across x-axis
  • Red flags:
    • Curved pattern = non-linearity
    • Funnel shape = heteroscedasticity

Plot 2: Normal Q-Q (Quantile-Quantile)

  • A Q-Q plot compares the distribution of your residuals to a theoretical normal distribution.
  • What to look for: Points following the diagonal reference line
  • What it checks: Normality of residuals
  • Points close around the diagonal indicate residuals are normally distributed

4.3 Checking for Multicollinearity

Multicollinearity occurs when predictors are highly correlated, which can:

  • Inflate standard errors
  • Make individual coefficients unstable
  • Lead to counterintuitive results

4.3.1 Variance Inflation Factor (VIF)

VIF quantifies how much multicollinearity inflates the variance (and standard errors) of regression coefficients.

How VIF works:

For each predictor \(X_1\):

  1. Regress \(X_1\) on all other predictors
  2. Get \(R^2\) from that regression (how well other predictors explain \(X_1\))
  3. Calculate: \(\text{VIF} = \frac{1}{1 - R^2}\)
  • Rule of Thumb: VIF > 10 (or Tolerance < 0.1) indicates problematic multicollinearity.

We can get VIF values by using the vif() function in R.

# Calculate VIF
vif_values <- car::vif(model_multiple)

tibble(
  Variable = names(vif_values),
  VIF = round(vif_values, 2),
  Tolerance = round(1/vif_values, 3),
  Interpretation = case_when(
    vif_values < 5 ~ "Acceptable",
    vif_values < 10 ~ "Moderate concern",
    TRUE ~ "High - consider removing"
  )
) %>%
  kable(caption = "Multicollinearity Diagnostics") %>%

4.3.2 Demonstrating the Impact of Multicollinearity

Let’s see what happens when we include two highly correlated predictors in the same model.

Scenario: We want to understand what predicts longer hospital length of stay. We have two predictors:

  • Number of comorbidities (chronic conditions like diabetes, COPD, etc.)
  • Number of medications (prescribed at admission)

These variables are highly correlated (r ≈ 0.90) because patients with more conditions naturally take more medications.

# Generate demonstration data
set.seed(2026)
n <- 200

demo_data <- tibble(
  num_comorbidities = sample(0:5, n, replace = TRUE, prob = c(0.15, 0.25, 0.25, 0.20, 0.10, 0.05)),
  num_medications = round(2.5 * num_comorbidities + rnorm(n, mean = 1, sd = 1.2)),
  los = round(3 + 2.0 * num_comorbidities - 0.4 * num_medications + rnorm(n, 0, 1.5), 1)
) %>%
  mutate(
    num_medications = pmax(0, num_medications),  # No negative medications
    los = pmax(1, los)  # Minimum 1 day stay
  )

# Check correlation
correlation <- cor(demo_data$num_comorbidities, demo_data$num_medications)
cat("Correlation between comorbidities and medications:", round(correlation, 3), "\n")
Correlation between comorbidities and medications: 0.94

Now let’s fit three models and compare:

# Model 1: Comorbidities alone
model_1 <- lm(los ~ num_comorbidities, data = demo_data)

# Model 2: Medications alone
model_2 <- lm(los ~ num_medications, data = demo_data)

# Model 3: Both together (multicollinearity!)
model_3 <- lm(los ~ num_comorbidities + num_medications, data = demo_data)

    summary(model_3)$coefficients[3, 2]

What happened?

  1. Model 1 (comorbidities alone):
    • Significant positive effect (each additional comorbidity increases LOS)
  2. Model 2 (medications alone):
    • Significant positive effect (each additional medication increases LOS)
  3. Model 3 (both together): The truth is revealed!
    • Comorbidities: Remains positive and significant
    • Medications: Coefficient dramatically changes (from +0.28 to -0.33)!
    • Standard errors inflate dramatically (VIF ≈ 8.6)

Why the dramatic change?

  • When medications is alone in the model, it picks up the effect of comorbidities (since they’re correlated). It looks important!

  • But when both are included, the model separates their effects. Now we see that after controlling for comorbidities, medications shows its true relationship (which may be weak, non-significant, or even negative)

  • Multicollinearity doesn’t just inflate standard errors. It can completely mislead you about which predictors matter and even the direction of their effects!

What to do:

  • Choose the most theoretically important predictor (usually comorbidities)
  • Or create a composite measure (e.g., “patient complexity index”)
  • Check correlation matrix before modeling to identify problems early

5 Summary

5.1 Key Takeaways

5.1.1 Simple vs. Multiple Linear Regression

  • Simple regression: Examines how one factor relates to an outcome (“If X increases by 1, how much does Y change?”)
  • Multiple regression: Examines how several factors together relate to an outcome, showing each factor’s unique contribution while holding others constant

5.1.2 How OLS Finds the Best Line

  • Ordinary Least Squares (OLS) finds the line that minimizes the sum of squared residuals
  • “Residuals” = vertical distance between actual data points and the fitted line

5.1.3 Model Fit: R²

  • R² tells you what percentage of variation your model explains
  • Adjusted R² is better for multiple regression (accounts for number of predictors)
  • Higher is better, but context matters

5.1.4 Making Predictions

  • Use fitted models to predict outcomes for new situations
  • Useful for “what-if” scenarios and planning

5.1.5 Interpreting Coefficients

Ask three questions for each coefficient:

  1. Direction: Positive or negative relationship?
  2. Magnitude: How large is the effect practically?
  3. Significance: Is p < 0.05? (But practical significance matters too!)

Key concept: In multiple regression, coefficients show effects while controlling for other variables.

5.1.6 Multicollinearity

  • Problem: When predictors are highly correlated, coefficients become unstable and can even flip signs
  • Check: VIF > 10 indicates problems
  • Solution: Remove or combine correlated predictors
