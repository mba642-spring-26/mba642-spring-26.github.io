1 Introduction to Linear Regression

1.1 Why Linear Regression in Healthcare?

Linear regression is one of the most fundamental and widely used statistical techniques in healthcare analytics. As a healthcare manager, you will frequently encounter situations where understanding relationships between variables is crucial for decision-making:

  • Resource allocation: How does nurse staffing level affect patient outcomes?
  • Cost management: What factors drive hospital readmission costs?
  • Quality improvement: How does patient wait time impact satisfaction scores?
  • Performance prediction: Can we predict length of stay based on patient characteristics?

Linear regression provides a powerful framework to:

  1. Quantify relationships between variables (e.g., “For every additional nurse per patient, satisfaction increases by X points”)
  2. Test hypotheses about whether relationships are statistically significant
  3. Make predictions about future outcomes
  4. Control for confounding variables when examining effects of interest

1.3 Key Terminology

Before we dive in, let’s establish key terminology:

  • Dependent Variable (DV): The outcome we want to predict or explain (also called response variable or Y)
  • Independent Variable (IV): The predictor(s) we use to explain the outcome (also called predictor variable or X)
  • Regression Coefficient (β): The slope that quantifies the relationship between an IV and the DV
  • Intercept (α or β₀): The predicted value of Y when all X variables equal zero
  • Residual (ε): The difference between observed and predicted values

2 Simple Linear Regression

2.1 The Concept

Simple linear regression models the relationship between one independent variable (X) and one dependent variable (Y) using a straight line. The goal is to find the “best-fitting” line through the data points.

2.1.1 The Model Equation

The simple linear regression model is expressed as:

\[Y_i = \beta_0 + \beta_1 X_i + \epsilon_i\]

Where:

  • \(Y_i\) = Observed value of the dependent variable for observation \(i\)
  • \(\beta_0\) = Intercept (the value of Y when X = 0)
  • \(\beta_1\) = Slope (the change in Y for a one-unit increase in X)
  • \(X_i\) = Value of the independent variable for observation \(i\)
  • \(\epsilon_i\) = Residual (error term) for observation \(i\)

2.1.2 Understanding the Components

The Intercept (β₀): The intercept represents the predicted value of Y when X equals zero. In healthcare contexts, this may or may not have a meaningful interpretation. For example, if X is “years of nursing experience,” an intercept would represent the predicted outcome for a nurse with zero years of experience.

The Slope (β₁): The slope is the key parameter of interest. It tells us:

  • Direction: Positive slope = positive relationship; Negative slope = negative relationship
  • Magnitude: How much Y changes for each one-unit increase in X
  • Statistical significance: Whether the relationship is likely to exist in the population (not just due to chance)

2.2 The Ordinary Least Squares (OLS) Method

2.2.1 How OLS Works

Linear regression finds the “best” line by minimizing the sum of squared residuals (SSR):

\[SSR = \sum_{i=1}^{n} (Y_i - \hat{Y}_i)^2 = \sum_{i=1}^{n} \epsilon_i^2\]

Where \(\hat{Y}_i\) is the predicted value for observation \(i\).

Why squared residuals?

  1. Squaring ensures positive and negative errors don’t cancel out
  2. Squaring penalizes larger errors more heavily
  3. Leads to closed-form mathematical solutions

2.2.2 Visual Intuition

# Create example data
example_data <- tibble(

)

# Fit model

Interpretation: Wait time explains 47.5% of the variance in patient satisfaction scores. The remaining 52.5% is explained by other factors not included in this model (e.g., staff friendliness, treatment effectiveness, facility cleanliness).

3 Multiple Linear Regression

3.1 Extending to Multiple Predictors

In reality, outcomes in healthcare are influenced by many factors simultaneously. Multiple linear regression allows us to:

  1. Include multiple predictors to better explain variance in the outcome
  2. Control for confounding variables when examining specific relationships
  3. Compare the relative importance of different predictors

3.1.1 The Model Equation

\[Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \cdots + \beta_k X_{ki} + \epsilon_i\]

Where:

  • \(\beta_0\) = Intercept
  • \(\beta_1, \beta_2, \ldots, \beta_k\) = Regression coefficients for each predictor
  • \(X_{1i}, X_{2i}, \ldots, X_{ki}\) = Values of predictors for observation \(i\)
  • \(\epsilon_i\) = Residual

Critical Concept: In multiple regression, each coefficient represents the effect of that variable holding all other variables constant (also called the “partial” or “conditional” effect).

3.2 Healthcare Example: Hospital Length of Stay

Let’s predict hospital length of stay (LOS) based on patient characteristics. This is a common application in healthcare operations and resource planning.

3.2.1 Creating Comprehensive Healthcare Data

# Generate synthetic hospital data
n <- 300

hospital_data <- tibble(
  patient_id = 1:n,
  age = round(rnorm(n, mean = 55, sd = 18)),
  severity_score = round(runif(n, 1, 10), 1),  # 1-10 scale
  num_comorbidities = rpois(n, lambda = 2),
  has_insurance = rbinom(n, 1, 0.85)
) %>%
  mutate(
    # Ensure realistic age bounds
    age = pmax(18, pmin(age, 95)),
    # Generate LOS based on predictors
    length_of_stay = round(
      1.5 +                          # Base stay
      0.04 * age +                   # Age effect
      0.6 * severity_score +         # Severity effect
      0.8 * num_comorbidities +      # Comorbidity effect
      -0.5 * has_insurance +         # Insurance effect (better care coordination)
      rnorm(n, 0, 1.5),              # Random error
      1
    ),
    # Ensure positive LOS
    length_of_stay = pmax(1, length_of_stay),
    # Create categorical insurance variable
    insurance_status = factor(has_insurance, levels = c(0, 1),
                              labels = c("Uninsured", "Insured"))
  )

# Summary statistics

4 Model Assumptions and Diagnostics

4.1 Key Assumptions of Linear Regression

For valid inference, linear regression requires several assumptions:

  1. Linearity: The relationship between X and Y is linear
  2. Independence: Observations are independent of each other
  3. Homoscedasticity: Constant variance of residuals across all levels of X
  4. Normality: Residuals are normally distributed (for inference)
  5. No perfect multicollinearity: Predictors are not perfectly correlated

4.2 Diagnostic Plots

# Create diagnostic plots
par(mfrow = c(2, 2))
plot(model_multiple)
par(mfrow = c(1, 1))

4.2.1 Interpreting Diagnostic Plots

  1. Residuals vs Fitted: Check for linearity and homoscedasticity. Want: random scatter around 0.

  2. Normal Q-Q: Check normality of residuals. Want: points following the diagonal line.

  3. Scale-Location: Check homoscedasticity. Want: horizontal line with equal spread.

  4. Residuals vs Leverage: Identify influential observations. Watch for points in upper/lower right corners.

4.3 Checking for Multicollinearity

Multicollinearity occurs when predictors are highly correlated, which can:

  • Inflate standard errors
  • Make individual coefficients unstable
  • Lead to counterintuitive results

4.3.1 Variance Inflation Factor (VIF)

7 Summary

7.1 Key Takeaways

7.1.1 Simple Linear Regression

  • Models the relationship between one predictor and one outcome
  • Equation: \(Y = \beta_0 + \beta_1 X + \epsilon\)
  • Coefficient (\(\beta_1\)) shows the change in Y for a one-unit change in X

7.1.2 Multiple Linear Regression

  • Models the relationship between multiple predictors and one outcome
  • Equation: \(Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_k X_k + \epsilon\)
  • Each coefficient shows the effect controlling for other variables

7.1.3 Interpretation Framework

For each coefficient, consider: 1. Direction: Positive or negative? 2. Magnitude: How large is the effect? 3. Statistical significance: Is p < 0.05?

7.1.4 Model Evaluation

  • R²/Adjusted R²: Proportion of variance explained
  • F-test: Overall model significance
  • Residual diagnostics: Check assumptions
  • VIF: Check for multicollinearity

7.1.5 Healthcare Applications

  • Predict outcomes: Length of stay, costs, satisfaction
  • Identify drivers: What factors influence readmissions?
  • Inform decisions: How much should we invest in staffing?
  • Control for confounders: Isolate the effect of interest
