2 Common Errors and How to Fix Them

You WILL encounter errors while practicing—that’s completely normal and part of the learning process! Here are the most common errors and their solutions:

2.1 Error 1: “object not found”

Error: object 'practice_data' not found

Cause: You didn’t run the chunk that creates the dataset

Fix:

  1. Scroll to the relevant section (Activity 1, 2, or 3)
  2. Find the “Dataset Generation” chunk
  3. Click the green “play” button to run that chunk
  4. Then try your code again

2.2 Error 2: “could not find function lm”

Error: could not find function "lm"

Cause: This shouldn’t happen (lm is built-in), but if it does, restart R

Fix: Session → Restart R, then run the setup chunk at the top

2.3 Error 3: Formula syntax errors

Error: invalid formula

Cause: Incorrect formula syntax in lm()

Common mistakes:

# ❌ Wrong: Missing tilde (~)
lm(y = x, data = data)

# ✅ Right: Use tilde to separate outcome and predictor
lm(y ~ x, data = data)

# ❌ Wrong: Comma instead of plus for multiple predictors
lm(y ~ x1, x2, data = data)

# ✅ Right: Use + to add multiple predictors
lm(y ~ x1 + x2, data = data)

2.4 Error 4: “undefined columns selected”

Error: undefined columns selected

Cause: Variable name doesn’t exist in the dataset (typo or wrong name)

Fix: Use names(your_data) to see exact variable names (R is case-sensitive!)

2.5 Still Stuck?

If you’re still getting errors:

  1. Check spelling: Variable names are case-sensitive
  2. Run all previous chunks: Make sure all setup code has been executed
  3. Restart R: Session → Restart R, then run chunks from top to bottom
  4. Read the error message carefully: It often tells you exactly what’s wrong
  5. Compare with lecture examples: Look at the lecture file for similar code
TipPro Tip: Debugging Strategy

When you get an error:

  1. Don’t panic! Errors are learning opportunities
  2. Read the error message - what line is it pointing to?
  3. Check the basics - Did you run all previous chunks? Are variable names spelled correctly?
  4. Simplify - Try running parts of your code separately to find which line causes the error
  5. Use summary() - Check your model object with summary(model_name) to see if it worked

10.3 Common Interpretation Mistakes to Avoid

  1. Confusing association with causation: Regression shows associations, not causes. Just because X predicts Y doesn’t mean X causes Y.

  2. Ignoring practical significance: A statistically significant result (p < 0.05) may not be practically important. Always consider magnitude!

  3. Extrapolating beyond the data: Predictions are most reliable within the range of observed predictor values.

  4. Misinterpreting multiple regression coefficients: Each coefficient shows the effect holding other variables constant, not the total effect.

  5. Ignoring multicollinearity: High multicollinearity makes coefficients unstable and hard to interpret, even if R² is high.

## Quick Reference: Regression Workflow

| Step | What to Do | R Code |
|------|-----------|--------|
| **1. Visualize** | Create scatterplot to see relationship | `ggplot(data, aes(x, y)) + geom_point() + geom_smooth(method = "lm")` |
| **2. Fit Model** | Simple regression | `lm(outcome ~ predictor, data = data)` |
| | Multiple regression | `lm(outcome ~ pred1 + pred2 + pred3, data = data)` |
| **3. Interpret** | View summary | `summary(model)` |
| | Extract coefficients | `coef(model)` or `tidy(model)` |
| **4. Assess Fit** | Check R² | `summary(model)$r.squared` |
| **5. Predict** | Make predictions | `predict(model, newdata = new_data)` |
| **6. Diagnose** | Check assumptions | `plot(model, which = 1:2)` |
| | Check multicollinearity | `car::vif(model)` |

## Common Interpretation Mistakes to Avoid

1. **Confusing association with causation**: Regression shows associations, not causes. Just because X predicts Y doesn't mean X causes Y.

2. **Ignoring practical significance**: A statistically significant result (p < 0.05) may not be practically important. Always consider magnitude!

3. **Extrapolating beyond the data**: Predictions are most reliable within the range of observed predictor values.

4. **Misinterpreting multiple regression coefficients**: Each coefficient shows the effect **holding other variables constant**, not the total effect.

5. **Ignoring multicollinearity**: High multicollinearity makes coefficients unstable and hard to interpret, even if R² is high.
