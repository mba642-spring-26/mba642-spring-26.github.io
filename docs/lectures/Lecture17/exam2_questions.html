Task 5b: Ridge Regression with Cross-Validation (2 points)

Fitting an OLS regression with 18 predictors (many of which are likely correlated administrative noise) risks overfitting and unstable coefficients. Ridge regression addresses this by shrinking coefficients toward zero, trading a bit of bias for substantially lower variance. The strength of shrinkage is controlled by lambda, which you choose via 10-fold cross-validation.

Fit a Ridge model with 10-fold cross-validation, plot the CV curve, and compute the test RMSE at lambda.1se.

ridge_cv <- cv.glmnet(
  x      = ___,
  y      = ___,
  alpha  = ___,
  nfolds = 10
)

plot(___)
title("Ridge Regression: Cross-Validation Results", line = 3)

ridge_coef <- coef(ridge_cv, s = "___")
ridge_pred <- predict(ridge_cv, s = "___", newx = ___)
ridge_rmse <- sqrt(mean((y_test - ridge_pred)^2))

cat("Non-zero Ridge coefficients:",
    sum(ridge_coef[-1] != 0), "out of", length(predictor_vars), "\n")
