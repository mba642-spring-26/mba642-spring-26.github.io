1 Overview

Welcome to the hands-on practice session! This document contains guided exercises to reinforce what you learned in the lecture.

What you’ll practice:

  • Creating variables and working with data types
  • Building and manipulating vectors
  • Working with data frames
  • Using dplyr functions for data wrangling
  • Creating your first analysis in Quarto

Format: Fill-in-the-blank code sections (marked with ___)

Instructions:

  1. Complete the code by replacing ___ with appropriate values
  2. Run each chunk to verify your code works
  3. Answer the interpretation questions
  4. Don’t worry about mistakes - they’re part of learning!

2 Common Errors and How to Fix Them

You WILL encounter errors - that’s completely normal! Here are the most common ones:

2.1 Error 1: “object not found”

Error: object 'patient_data' not found

Cause: You didn’t run the chunk that creates the dataset

Fix: Scroll up, run the data generation chunk, then try again

2.2 Error 2: “could not find function”

Error: could not find function "filter"

Cause: The tidyverse package isn’t loaded

Fix: Run the setup chunk at the top of this document that has library(tidyverse)

2.3 Error 3: Spelling and capitalization

R is case-sensitive! Age ≠ age

Fix: Use names(data_frame) to check exact column names

2.4 Error 4: Missing comma or parenthesis

# ❌ Wrong:
c(1, 2, 3 4, 5)

# ✅ Right:
c(1, 2, 3, 4, 5)

Fix: Count your parentheses and commas carefully

TipTip: When You Get Stuck
  1. Read the error message: It often tells you exactly what’s wrong
  2. Check your spelling and capitalization
  3. Make sure you ran all previous chunks
  4. Try running your code line by line to find the problem
  5. Ask your classmates or instructor!

6 Summary and Reflection

6.1 What You Practiced Today

✓ Creating variables with different data types ✓ Working with vectors and data frames ✓ Using dplyr verbs: select(), filter(), mutate(), arrange(), summarize() ✓ Grouping data with group_by() ✓ Combining operations with the pipe |> ✓ Creating a Quarto report

6.2 Key Concepts to Remember

ImportantEssential Takeaways
  1. The pipe |> makes code readable - chain operations together
  2. group_by() + summarize() is powerful - analyze by groups
  3. Comments explain your code - use # liberally
  4. Quarto makes work reproducible - code + narrative + output
  5. Practice makes perfect - the more you code, the easier it gets!
