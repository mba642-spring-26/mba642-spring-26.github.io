1 Introduction to R and RStudio

1.1 What is R?

R is a programming language and software environment specifically designed for statistical computing and data analysis. Originally developed in the early 1990s by Ross Ihaka and Robert Gentleman at the University of Auckland, New Zealand, R has become one of the most widely used tools for data science and analytics.

1.1.1 Why R for Healthcare Analytics?

R offers several compelling advantages for healthcare management professionals:

  1. Free and Open Source: Unlike expensive proprietary software (SAS, SPSS), R is completely free
  2. Extensive Healthcare Packages: Specialized packages for survival analysis, epidemiology, clinical trials, and health economics
  3. Reproducibility: Create documented, reproducible analyses essential for regulatory compliance and research
  4. Visualization: Create publication-quality graphs and interactive dashboards
  5. Community Support: Large community of healthcare data scientists sharing code and solutions
  6. Industry Adoption: Increasingly used by hospitals, pharmaceutical companies, insurance providers, and public health organizations

1.1.2 R’s Popularity in Data Science

According to various surveys and rankings:

  • Consistently ranked in the top 10 programming languages for data science
  • Over 20,000 packages available on CRAN (Comprehensive R Archive Network)
  • Widely used in academic research, with thousands of peer-reviewed papers using R
  • Growing adoption in healthcare industry for predictive analytics, outcomes research, and quality improvement

1.2 What is RStudio?

RStudio is an Integrated Development Environment (IDE) for R. Think of it as a user-friendly workspace that makes working with R much easier and more efficient.

Analogy: If R is the engine of a car, RStudio is the dashboard, steering wheel, and all the controls that help you drive effectively.

1.2.1 Benefits of Using RStudio

  • Organized workspace with multiple panes
  • Code completion and syntax highlighting
  • Easy package management
  • Integrated help and documentation
  • Version control integration (Git)
  • Direct creation of reports and presentations (via Quarto/R Markdown)

1.3 Installing R and RStudio

1.3.1 Step 1: Install R

  1. Go to https://cran.r-project.org/
  2. Click on your operating system (Windows, Mac, or Linux)
  3. Download and run the installer
  4. Follow the installation prompts (default settings are fine)

1.3.2 Step 2: Install RStudio

  1. Go to https://posit.co/download/rstudio-desktop/
  2. Download RStudio Desktop (Free version)
  3. Run the installer
  4. Follow the installation prompts
Important

Important: Always install R first, then RStudio. RStudio needs R to function.

2 The RStudio Interface

When you open RStudio, you’ll see four main panes (panels). Understanding these is crucial for working efficiently.

2.1 The Four Panes

2.1.1 1. Source Pane (Top-Left)

  • Where you write and edit your R scripts and Quarto documents
  • Code here is NOT executed until you run it
  • Save your work here for future use
  • Think of it as your “notepad” for code

2.1.2 2. Console Pane (Bottom-Left)

  • Where R actually executes commands
  • Shows output and results
  • Can type commands directly here (but they won’t be saved)
  • Displays error messages and warnings

2.1.3 3. Environment/History Pane (Top-Right)

  • Environment tab: Shows all objects (data, variables) currently in memory
  • History tab: Record of all commands you’ve run
  • Connections tab: Database connections
  • Think of Environment as your “workspace inventory”

2.1.4 4. Files/Plots/Packages/Help Pane (Bottom-Right)

  • Files: Navigate your computer’s file system
  • Plots: Displays graphs and visualizations
  • Packages: Install and manage R packages
  • Help: Access documentation and help files
  • Viewer: Preview HTML content and Quarto documents

2.2 Essential RStudio Settings

Go to Tools → Global Options to customize:

  • Appearance: Change font size and theme (dark mode available!)
  • Code: Enable/disable code completion
  • Pane Layout: Rearrange the four panes
Tip

Tip: Consider using a dark theme to reduce eye strain during long coding sessions.

3 Introduction to Quarto

3.1 What is Quarto?

Quarto is an open-source scientific and technical publishing system that allows you to combine:

  • Code (R, Python, and other languages)
  • Text (formatted with Markdown)
  • Output (tables, figures, results)

…all in a single document that can be rendered to multiple formats (HTML, PDF, Word, presentations).

3.1.1 Why Use Quarto?

  1. Reproducibility: Your analysis and documentation are in one place
  2. Professional Reports: Create polished reports directly from your analysis
  3. Multiple Formats: One source document → many output formats
  4. Version Control Friendly: Plain text files work well with Git
  5. Collaboration: Easy to share and review

3.1.2 Quarto vs R Markdown

Quarto is the next-generation version of R Markdown. If you’ve heard of R Markdown, Quarto offers:

  • Better support for multiple programming languages
  • Improved features for books, websites, and presentations
  • More consistent syntax across output formats

3.2 Basic Quarto Document Structure

A Quarto document (.qmd file) has three main parts:

3.2.1 1. YAML Header

---
title: "My Analysis"
author: "Your Name"
date: today
format: html
---

This controls document metadata and output settings.

3.2.2 2. Markdown Text

Regular text with formatting:

# Heading 1
## Heading 2

**Bold text** and *italic text*

- Bullet point 1
- Bullet point 2

1. Numbered item 1
2. Numbered item 2

3.2.3 3. Code Chunks

R code is placed in special “chunks”:


::: {.cell}

```{.r .cell-code}
# Your R code here
mean(c(1, 2, 3, 4, 5))
```

::: {.cell-output .cell-output-stdout}

```
[1] 3
```

Numbers with or without decimals.

TRUE or FALSE values.

7 Packages and the Tidyverse

7.1 What are Packages?

Packages are collections of R functions, data, and documentation that extend R’s capabilities. Think of them as “apps” for R.

You only need to install a package once (like downloading an app).

The tidyverse is a collection of R packages designed for data science. They share a common philosophy and grammar, making them easy to learn and use together.

7.2.2 The Tidyverse Philosophy

  1. Tidy data: Each variable is a column, each observation is a row
  2. Consistent syntax: Functions work similarly across packages
  3. Pipe-friendly: Chain operations together with |> or %>%
  4. Human-readable: Code reads almost like English

8 Data Wrangling with dplyr

Data wrangling (also called data munging) is the process of cleaning, transforming, and preparing data for analysis. The dplyr package provides intuitive functions for these tasks.

8.1 The Pipe Operator

Before we dive in, let’s learn the pipe operator |> (or %>%). It takes the output of one function and passes it as the first argument to the next function.

# Without pipe - nested functions (hard to read)
round(mean(c(1, 2, 3, 4, 5)), 2)
[1] 3
# With pipe - sequential operations (easy to read)
c(1, 2, 3, 4, 5) |>
  mean() |>
  round(2)
[1] 3

Read it as “and then”: Take this data, and then do this, and then do that.
