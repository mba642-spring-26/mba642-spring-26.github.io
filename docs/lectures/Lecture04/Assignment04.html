2 About the Dataset

Hospital Administrative Data

For this assignment, we will use the healthyR_data dataset from the healthyR.data package. This is a realistic healthcare administrative dataset containing hospital visit records with patient, financial, and quality information.

2.1 Dataset Background

The healthyR_data dataset simulates administrative data from a hospital system, including:

  • Patient visit information: When patients arrived and left, how long they stayed
  • Financial data: Charges, payments, adjustments, and amounts due
  • Service categories: Which departments/service lines provided care
  • Quality indicators: Readmission flags and length of stay comparisons

This type of data is commonly used by healthcare managers to analyze operational efficiency, financial performance, and quality metrics.
