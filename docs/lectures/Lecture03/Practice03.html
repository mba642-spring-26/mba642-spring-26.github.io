1 Introduction

1.1 What You Learned in Lecture

In today’s lecture, you learned the basic statistical concepts needed for data analysis:

  1. Central Tendency & Dispersion - The fundamental tools for summarizing data
    • Mean, median, mode (where the central, typical value is)
    • Standard deviation, variance, range (how spread out the data is)
  2. Measurement Scales - When each tool is appropriate to use
    • Nominal → frequencies and mode only
    • Ordinal → add median (but NOT mean!)
    • Interval/Ratio → can use mean and SD
  3. Distribution Shapes - Four common shapes and what they mean
    • Normal/Symmetric → use mean; Empirical rule (68-95-99.7)
    • Right-skewed → use median (typical for healthcare LOS, costs)
    • Left-skewed → use median (e.g., high satisfaction scores)
    • Bimodal → use the modes, analyze subgroups separately
  4. Confidence Intervals - Quantifying uncertainty around estimates

1.2 What You’ll Do in This Workbook

This practice session gives you hands-on experience applying these concepts to a dataset. You’ll work with patient satisfaction survey data to:

  • Identify measurement scales and choose appropriate statistics
  • Calculate descriptive statistics (mean, median, SD, Mode)
  • Visualize distribution shapes
  • Apply the empirical rule
  • Calculate and interpret confidence intervals

2 Dataset: Patient Satisfaction Survey

2.1 Background and Context

2.1.1 The Scenario

You are a Data Analyst at a regional healthcare system that operates three hospitals: General Hospital, University Medical, and Community Health. The system recently conducted a comprehensive patient satisfaction survey across all facilities to:

  • Assess overall patient experience
  • Identify areas for quality improvement
  • Compare performance across departments
  • Meet regulatory reporting requirements (HCAHPS; Hospital Customer Assessment of Healthcare Providers and Systems)

The Chief Quality Officer has asked you to analyze the survey data and provide insights that will inform strategic decisions about:

  • Resource allocation
  • Quality improvement initiatives
  • Staff training priorities
  • Performance benchmarking

2.1.2 About the Data

This hypothetical dataset contains 200 patient survey responses collected over a 3-month period. Each row represents one patient’s complete survey response and visit information.

Key features of this dataset:

  • Includes different data types (nominal, ordinal, interval, ratio)
  • All variables are commonly tracked in hospital quality programs
  • Designed to support practical decision-making

Data collection period: Q1 2024 (January - March) Survey response rate: 68% (typical for patient satisfaction surveys) Survey method: Post-discharge email survey

2.1.3 Why This Dataset Matters

Patient satisfaction data is critical for healthcare organizations because:

  1. Regulatory compliance: Centers for Medicare & Medicaid Services (CMS) ties hospital reimbursement to HCAHPS scores
  2. Quality indicator: Satisfaction correlates with clinical outcomes, safety, and adherence
  3. Competitive advantage: Public reporting influences patient choice
  4. Operational improvement: Identifies specific pain points in care delivery

Understanding how to properly analyze this type of data is an essential skill for healthcare managers.

Run this code to generate the patient satisfaction dataset:

# Create patient satisfaction data
patient_satisfaction <- tibble(
  patient_id = 1:200,
  hospital = sample(c("General Hospital", "University Medical", "Community Health"),
                    200, replace = TRUE),
  department = sample(c("Emergency", "Surgery", "Internal Medicine", "Pediatrics"),
                      200, replace = TRUE),
  age = round(rnorm(200, mean = 55, sd = 18)),
  gender = sample(c("Male", "Female"), 200, replace = TRUE),
  insurance_type = sample(c("Private", "Medicare", "Medicaid", "Uninsured"), 200,
                          prob = c(0.4, 0.35, 0.15, 0.1), replace = TRUE),
  wait_time_minutes = round(rgamma(200, shape = 2, rate = 0.05)),
  satisfaction_score = round(pmin(7, pmax(1, rnorm(200, mean = 5.2, sd = 1.3)))),
  would_recommend = sample(1:7, 200, replace = TRUE,
                           prob = c(0.05, 0.05, 0.1, 0.15, 0.25, 0.25, 0.15)),
  length_of_stay = round(rgamma(200, shape = 1.5, rate = 0.3), 1),
  total_charges = round(rlnorm(200, meanlog = 9, sdlog = 1))
) %>%
  mutate(
    age = pmax(18, pmin(age, 95)),  # Keep age realistic
    age_group = case_when(
      age < 45 ~ "18-44",
      age < 65 ~ "45-64",
      age < 75 ~ "65-74",
      TRUE ~ "75+"
    ),
    age_group = factor(age_group, levels = c("18-44", "45-64", "65-74", "75+")),
    # Create pain category variable (ordinal)
    pain_category = sample(c("None", "Mild", "Moderate", "Severe"), 200,
                          prob = c(0.25, 0.35, 0.30, 0.10), replace = TRUE),
    pain_category = factor(pain_category, levels = c("None", "Mild", "Moderate", "Severe"))
  )

2.4.3 Important Notes on Measurement Scales

  • Nominal variables (hospital, department, insurance_type, gender): Categories with no inherent order. Use mode, frequencies, shares only.

  • Ordinal variables (age_group, pain_category): Categories with meaningful order, but intervals between categories are NOT equal. Use mode, median, frequencies, and shares. Do NOT calculate means!

  • Quasi-Interval variables (satisfaction_score, would_recommend): Numeric rating scales that are technically ordinal but treated as interval by convention in healthcare. Can use mean and SD.

  • Ratio variables (age, wait_time_minutes, length_of_stay, total_charges): Have equal intervals AND a true zero point. Can use all statistics (mean, median, SD, etc.). Consider distribution shape when choosing which to report.

4.1 R Functions for Descriptive Statistics

Before we start calculating statistics, let’s review the key R functions you’ll need. These functions make it easy to calculate central tendency and dispersion measures.

4.1.1 Central Tendency Functions

# Create example data
example_data <- c(2, 3, 3, 4, 5, 5, 6, 8, 15)

# Mean (average)
mean(example_data)          

# Median (middle value)
median(example_data)        

# Mode (most frequent) 
Mode(example_data)  # The Mode function from the DescTools package

4.1.2 Dispersion Functions

# Standard Deviation
sd(example_data)            # 3.64

# Variance (SD squared)
var(example_data)           # 13.25

# Range (max - min)
range(example_data)         # range function returns c(2, 15) - both min and max

# Minimum and Maximum
min(example_data)           # 2
max(example_data)           # 15

# By using these numbers we can get Range manually
max(example_data) - min(example_data)  # 13

Interpretation: Notice how the mean is pulled toward the long tail (higher values). This confirms that median better represents the “typical” patient for right-skewed data.

Management insight: If you reported only the mean LOS, it would be inflated by a few very long stays. The median gives a more accurate picture of what most patients experience.

5 Activity 3: The Empirical Rule (68-95-99.7)

5.1 Task 3.1: Apply the Empirical Rule to Age

If age is approximately normally distributed, use the empirical rule to find where most patients fall.

# FILL IN: Calculate mean and SD
age_mean <- mean(patient_satisfaction$___)
age_sd <- sd(patient_satisfaction$___)

# Calculate ranges
range_1sd <- c(age_mean - ___, age_mean + ___)  # ±1 SD
range_2sd <- c(age_mean - 2*___, age_mean + 2*___)  # ±2 SD

cat("Mean age:", round(age_mean, 1), "years\n")
cat("SD:", round(age_sd, 1), "years\n\n")
cat("Using the Empirical Rule:\n")
cat("  68% of patients are between", round(range_1sd[1], 1), "and", round(range_1sd[2], 1), "years\n")
cat("  95% of patients are between", round(range_2sd[1], 1), "and", round(range_2sd[2], 1), "years\n")

8 Key Takeaways

After completing this practice workbook, you should be able to:

✓ Identify measurement scales and choose appropriate statistics ✓ Calculate descriptive statistics (mean, median, Mode, sd) ✓ Interpret distribution shapes and choose mean vs. median ✓ Apply the empirical rule to understand data spread ✓ Calculate and interpret confidence intervals

Remember:

  • Ordinal data → median, NOT mean!
  • Skewed data → median better represents “typical” value
  • Always report both mean and median for transparency when appropriate
  • Confidence intervals quantify uncertainty (not probability the parameter is in THIS interval)
  • Statistical significance ≠ Clinical/practical importance
