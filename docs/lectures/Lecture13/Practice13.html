2 Recap: Key Concepts

Before starting the activities, let’s review essential concepts from the lecture:

2.1 The Three Scales

Logistic regression works with three related measures:

  • Probability (p): Ranges from 0 to 1
  • Odds: Ranges from 0 to ∞, calculated as \(\frac{p}{1-p}\)
  • Log Odds (Logit): Ranges from −∞ to +∞, calculated as \(\ln(\text{Odds})\)

2.2 Converting Between Scales

# Probability → Odds → Log Odds
probability <- 0.3
odds <- probability / (1 - probability)
log_odds <- log(odds)

# Log Odds → Odds → Probability
log_odds <- -0.5
odds <- exp(log_odds)
probability <- odds / (1 + odds)

2.3 Running Logistic Regression in R

Simple logistic regression (one predictor):

model <- glm(outcome ~ predictor,
             data = your_data,
             family = binomial(link = "logit"))

summary(model)  # View results

Multiple logistic regression (multiple predictors):

model <- glm(outcome ~ predictor1 + predictor2 + predictor3,
             data = your_data,
             family = binomial(link = "logit"))

summary(model)  # View results

2.4 Interpreting Results

Coefficients (log odds ratios): - Negative coefficient → predictor decreases log odds of outcome - Positive coefficient → predictor increases log odds of outcome

Odds Ratios (exponentiated coefficients):

# Calculate odds ratios
odds_ratios <- exp(coef(model))
  • Odds ratio < 1 → predictor decreases odds of outcome
  • Odds ratio = 1 → no effect
  • Odds ratio > 1 → predictor increases odds of outcome

Percent change in odds:

If odds ratio = 0.85, then odds decrease by (1 - 0.85) × 100 = 15% If odds ratio = 1.20, then odds increase by (1.20 - 1) × 100 = 20%

2.5 Making Predictions

# Create new data
new_data <- data.frame(
  predictor1 = c(5, 7),
  predictor2 = c(60, 80)
)

# Predict probabilities
predicted_prob <- predict(model,
                         newdata = new_data,
                         type = "response")

Important: type = "response" returns probabilities. Without it, you get log odds.

2.6 Evaluating Classification

# Add predicted probabilities to data
data$predicted_prob <- predict(model, type = "response")

# Classify using 0.5 threshold
data$predicted_class <- ifelse(data$predicted_prob >= 0.5, 1, 0)

# Create confusion matrix
table(Predicted = data$predicted_class, Actual = data$outcome)

# Calculate accuracy
accuracy <- mean(data$predicted_class == data$outcome)

3 Common Errors and How to Fix Them

You WILL encounter errors while practicing—that’s completely normal and part of the learning process! Here are the most common errors specific to logistic regression and their solutions:

3.1 Error 1: “non-numeric argument to binary operator”

Error in predictor1 + predictor2: non-numeric argument to binary operator

Cause: You’re trying to use a character/factor variable directly in arithmetic operations

Fix: Make sure categorical variables are properly coded as factors:

# Check variable types
str(your_data)

# Convert to factor if needed
your_data$category <- factor(your_data$category)

3.2 Error 2: Forgetting family = binomial

# ❌ Wrong - this runs linear regression:
model <- glm(outcome ~ predictor, data = data)

# ✅ Right - this runs logistic regression:
model <- glm(outcome ~ predictor, data = data, family = binomial)

Fix: Always include family = binomial(link = "logit") or just family = binomial for logistic regression.

3.3 Error 3: Misinterpreting coefficients as odds ratios

Cause: The coefficients from summary() are log odds ratios, not odds ratios

Fix: Exponentiate to get odds ratios:

# ❌ Wrong - these are log odds ratios:
coef(model)

# ✅ Right - these are odds ratios:
exp(coef(model))

3.4 Error 4: Forgetting type = "response" in predictions

# ❌ Wrong - returns log odds:
predict(model, newdata = new_data)

# ✅ Right - returns probabilities:
predict(model, newdata = new_data, type = "response")

Fix: Always use type = "response" to get predicted probabilities.

3.5 Error 5: “contrasts can be applied only to factors with 2 or more levels”

Cause: Your categorical variable has only one level in your data

Fix: Check your data and make sure you have variation:

# Check levels
table(your_data$category)

# Make sure you have at least 2 levels with observations

3.6 Error 6: Incorrect calculation of percent change

# Example: odds ratio = 0.75
or <- 0.75

# ❌ Wrong:
pct_change <- or * 100  # This gives 75, which is wrong

# ✅ Right (for OR < 1):
pct_decrease <- (1 - or) * 100  # This gives 25% decrease

# Example: odds ratio = 1.30
or <- 1.30

# ✅ Right (for OR > 1):
pct_increase <- (or - 1) * 100  # This gives 30% increase

3.7 Still Stuck?

If you’re still getting errors:

  1. Check spelling: Variable names are case-sensitive
  2. Run setup chunk: Make sure you’ve loaded all libraries
  3. Check data structure: Use str(your_data) to verify variable types
  4. Read error messages carefully: They often tell you exactly what’s wrong
  5. Compare with lecture examples: Look for similar code patterns
TipPro Tip: Debugging Strategy

When you get an error:

  1. Don’t panic! Errors are learning opportunities
  2. Read the error message - what line is it pointing to?
  3. Check the basics - Did you include family = binomial? Did you use type = "response"?
  4. Simplify - Try running just the glm() first before making predictions
  5. Check the lecture - Find a similar example and compare your code

6 Activity 3: Surgical Complication Risk (Multiple Logistic Regression)

6.1 Scenario

A surgical department wants to predict the risk of post-operative complications (problems that occur after surgery). They have collected data on patient age (age), BMI (bmi - body mass index, a measure of body weight relative to height), surgery duration in minutes (surgery_duration), and whether the surgery was elective (planned) or emergency (surgery_type).

Post-operative complications represent a significant concern in surgical care, with factors such as patient characteristics, procedure complexity, and surgical urgency all potentially contributing to complication risk. Understanding which factors predict complications can help with risk stratification and targeted prevention strategies.

6.2 Dataset Generation

# Surgical complication data
n_surg <- 180

surgery_data <- data.frame(
  patient_id = 1:n_surg,
  age = round(rnorm(n_surg, 60, 15)),
  bmi = round(rnorm(n_surg, 28, 5), 1),
  surgery_duration = round(rnorm(n_surg, 120, 45)),
  surgery_type = sample(c("Elective", "Emergency"), n_surg,
                        replace = TRUE, prob = c(0.7, 0.3))
)

# Generate outcomes
surgery_data$age <- pmax(pmin(surgery_data$age, 90), 25)
surgery_data$bmi <- pmax(pmin(surgery_data$bmi, 45), 18)
surgery_data$surgery_duration <- pmax(surgery_data$surgery_duration, 30)

type_effect <- ifelse(surgery_data$surgery_type == "Emergency", 0.8, 0)

                 rnorm(n_surg, 0, 0.5)
prob_comp <- exp(log_odds_comp) / (1 + exp(log_odds_comp))
surgery_data$complication <- rbinom(n_surg, 1, prob_comp)

7 Activity 4: Diabetes Management Success (Multiple Logistic Regression)

7.1 Scenario

A diabetes clinic wants to predict which patients will achieve good blood sugar control. This is measured using HbA1c (a blood test that shows average blood sugar levels over the past 2-3 months). A value below 7% is considered good control.

The clinic has data on patient age (age), years since diagnosis (years_since_dx), number of clinic visits in the past year (clinic_visits), and whether they use insulin injections (uses_insulin).

Diabetes management success depends on multiple factors including patient engagement (reflected in clinic visit frequency), disease duration, treatment complexity, and age-related considerations. Understanding which factors predict successful glycemic control can help clinics target support resources effectively.

7.2 Dataset Generation

# Diabetes management data
n_dm <- 150

diabetes_data <- data.frame(
  patient_id = 1:n_dm,
  age = round(rnorm(n_dm, 58, 12)),
  years_since_dx = round(runif(n_dm, 1, 20)),
  clinic_visits = rpois(n_dm, lambda = 3),
  uses_insulin = sample(c("Yes", "No"), n_dm, replace = TRUE, prob = c(0.4, 0.6))
)

# Generate outcomes
diabetes_data$age <- pmax(pmin(diabetes_data$age, 85), 30)
insulin_effect <- ifelse(diabetes_data$uses_insulin == "Yes", -0.5, 0)

log_odds_control <- -1 + 0.02 * diabetes_data$age - 0.08 * diabetes_data$years_since_dx +
                    0.3 * diabetes_data$clinic_visits + insulin_effect +
                    rnorm(n_dm, 0, 0.6)
prob_control <- exp(log_odds_control) / (1 + exp(log_odds_control))
diabetes_data$good_control <- rbinom(n_dm, 1, prob_control)

# Recap: Key Concepts

Before starting the activities, let's review essential concepts from the lecture:

## The Three Scales

Logistic regression works with three related measures:

- **Probability (p)**: Ranges from 0 to 1
- **Odds**: Ranges from 0 to ∞, calculated as $\frac{p}{1-p}$
- **Log Odds (Logit)**: Ranges from −∞ to +∞, calculated as $\ln(\text{Odds})$

## Converting Between Scales

```{r}
#| label: example-conversion
#| eval: false

# Probability → Odds → Log Odds
probability <- 0.3
odds <- probability / (1 - probability)
log_odds <- log(odds)

# Log Odds → Odds → Probability
log_odds <- -0.5
odds <- exp(log_odds)
probability <- odds / (1 + odds)
```

## Interpreting Results

**Coefficients** (log odds ratios):
- **Negative** coefficient → predictor decreases log odds of outcome
- **Positive** coefficient → predictor increases log odds of outcome

**Odds Ratios** (exponentiated coefficients):

```{r}
#| label: example-or
#| eval: false

odds_ratios <- exp(coef(model))
```

- **Odds ratio < 1** → predictor decreases odds of outcome
- **Odds ratio = 1** → no effect
- **Odds ratio > 1** → predictor increases odds of outcome

**Percent change in odds**:

If odds ratio = 0.85, then odds decrease by (1 - 0.85) × 100 = 15%
If odds ratio = 1.20, then odds increase by (1.20 - 1) × 100 = 20%

# Common Errors and How to Fix Them

You **WILL** encounter errors while practicing—that's completely normal and part of the learning process! Here are the most common errors specific to logistic regression and their solutions:

## Error 1: "non-numeric argument to binary operator"

```r
Error in predictor1 + predictor2: non-numeric argument to binary operator
```

**Cause**: You're trying to use a character/factor variable directly in arithmetic operations

**Fix**: Make sure categorical variables are properly coded as factors:

```{r}
#| eval: false
# Check variable types
str(your_data)

# Convert to factor if needed
your_data$category <- factor(your_data$category)
```

## Error 2: Forgetting `family = binomial`

```r
# ❌ Wrong - this runs linear regression:
model <- glm(outcome ~ predictor, data = data)

# ✅ Right - this runs logistic regression:
model <- glm(outcome ~ predictor, data = data, family = binomial)
```

**Fix**: Always include `family = binomial(link = "logit")` or just `family = binomial` for logistic regression.

## Error 3: Misinterpreting coefficients as odds ratios

**Cause**: The coefficients from `summary()` are **log odds ratios**, not odds ratios

**Fix**: Exponentiate to get odds ratios:

```{r}
#| eval: false
# ❌ Wrong - these are log odds ratios:
coef(model)

# ✅ Right - these are odds ratios:
exp(coef(model))
```

## Error 4: Forgetting `type = "response"` in predictions

```{r}
#| eval: false
# ❌ Wrong - returns log odds:
predict(model, newdata = new_data)

# ✅ Right - returns probabilities:
predict(model, newdata = new_data, type = "response")
```

**Fix**: Always use `type = "response"` to get predicted probabilities.

## Error 5: "contrasts can be applied only to factors with 2 or more levels"

**Cause**: Your categorical variable has only one level in your data

**Fix**: Check your data and make sure you have variation:

```{r}
#| eval: false
# Check levels
table(your_data$category)

# Make sure you have at least 2 levels with observations
```

## Error 6: Incorrect calculation of percent change

```{r}
#| eval: false
# Example: odds ratio = 0.75
or <- 0.75

# ❌ Wrong:
pct_change <- or * 100  # This gives 75, which is wrong

# ✅ Right (for OR < 1):
pct_decrease <- (1 - or) * 100  # This gives 25% decrease

# Example: odds ratio = 1.30
or <- 1.30

# ✅ Right (for OR > 1):
pct_increase <- (or - 1) * 100  # This gives 30% increase
```

## Key Takeaways

After completing this practice activity, you should be able to:

- ✓ Run simple and multiple logistic regression using `glm()` with `family = binomial`
- ✓ Interpret log odds ratios and convert them to odds ratios using `exp()`
- ✓ Calculate percent changes in odds from odds ratios
- ✓ Make predictions using `predict()` with `type = "response"`
- ✓ Evaluate classification accuracy using confusion matrices
- ✓ Understand how controlling for confounders affects coefficient estimates

## Logistic Regression Quick Reference

| **Task** | **R Code** |
|----------|-----------|
| **Run simple logistic regression** | `glm(outcome ~ predictor, data, family = binomial)` |
| **Run multiple logistic regression** | `glm(outcome ~ pred1 + pred2 + pred3, data, family = binomial)` |
| **Get odds ratios** | `exp(coef(model))` |
| **Make predictions** | `predict(model, newdata, type = "response")` |
| **Classification** | `ifelse(predicted_prob >= 0.5, 1, 0)` |
| **Confusion matrix** | `table(Predicted = pred_class, Actual = actual)` |
| **Accuracy** | `mean(pred_class == actual)` |

## Interpretation Guide

**Odds Ratio Interpretation:**

- **OR < 1**: Protective factor (decreases odds)
  - Example: OR = 0.75 → 25% decrease in odds
  - Formula: `(1 - OR) × 100`

- **OR = 1**: No effect

- **OR > 1**: Risk factor (increases odds)
  - Example: OR = 1.30 → 30% increase in odds
  - Formula: `(OR - 1) × 100`

**In multiple regression**, remember:
- Each coefficient represents the effect **holding all other variables constant**
- This helps isolate the **independent effect** of each predictor
- Comparing simple vs. multiple regression reveals **confounding**
