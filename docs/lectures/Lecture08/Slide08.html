Part 1: Crosstabulation

What is Crosstabulation?

Crosstabulation (contingency table) tests whether two categorical variables are independent or associated.


The chi-square test of independence compares:

  • Observed frequencies: What we actually see in the data
  • Expected frequencies: What we would see if the variables were independent


A large discrepancy between observed and expected → evidence of association.

The Chi-Square Formula

\[\chi^2 = \sum \frac{(O_{ij} - E_{ij})^2}{E_{ij}}\]

Where the expected frequency for each cell is:

\[E_{ij} = \frac{(\text{Row Total}_i) \times (\text{Column Total}_j)}{\text{Grand Total}}\]


  • Larger χ² → greater discrepancy → stronger evidence against independence
  • p-value tells us the probability of seeing such a large χ² if variables were truly independent

Example: Insurance × Appointment Status

Observed frequencies:

No-show Attended Row Total
Medicare 15 35 50
Private 25 25 50
Col Total 40 60 100

Expected frequency (e.g., Medicare × No-show):

\[E = \frac{50 \times 40}{100} = 20\]

Chi-square contribution for that cell:

\[\frac{(15 - 20)^2}{20} = \frac{25}{20} = 1.25\]

Repeat for all 4 cells and sum → χ² statistic.

Key Assumption

For the chi-square test to be valid:

  • Each cell in the contingency table should have an expected frequency of at least 5.


When this assumption is violated → use Fisher’s exact test instead.

  • See the lecture notes for more details

Null and Alternative Hypotheses

  • H₀: Insurance type and readmission status are independent
  • Hₐ: Insurance type and readmission status are not independent

Conducting the Chi-Square Test

  • We can get the chi-square test results using the chisq.test() function
  • Inside the function, we need to provide the contingency table of the two variables
chi_result <- chisq.test(table(readmission_data$insurance,
                                readmission_data$readmission))
chi_result

    Pearson's Chi-squared test

data:  table(readmission_data$insurance, readmission_data$readmission)
X-squared = 19.274, df = 2, p-value = 6.527e-05

Checking Expected Frequencies

  • To check the expected frequencies, we can use the $expected attribute of the chi-square test result
  • These expected frequencies are calculated under the assumption of independence (under the null hypothesis H₀)
# Check expected frequencies (all should be ≥ 5)
chi_result$expected
          
           Not Readmitted Readmitted
  Medicaid       69.30667   22.69333
  Medicare      106.97333   35.02667
  Private        49.72000   16.28000

Interpreting the Results

  • χ² = 19.274: Measures overall discrepancy between observed and expected
  • df = 2: (rows - 1) × (cols - 1) = (3-1) × (2-1) = 2
  • p-value = 6.53e-05: Probability of this χ² or more extreme results if the null hypothesis were true (i.e., if insurance type and readmission status were independent)


Since p < 0.05, there is a statistically significant association between insurance type and readmission status.

  • Readmission rates are significantly different depending on insurance type (Medicare > Medicaid > Private)

Clinical Implications

  • Targeted discharge planning: Medicaid/Medicare patients may benefit from enhanced follow-up
  • Resource allocation: Focus quality improvement efforts on high-risk patient groups
  • Health equity: Disparities may reflect social determinants of health
  • Financial strategy: Understanding patterns of readmission by insurance type helps focus HRRP interventions

When Expected Frequencies Are Small

When any expected frequency < 5, the chi-square approximation becomes unreliable. Use Fisher’s exact test instead:


Decision Rule:

  1. Run chisq.test() and check expected frequencies with $expected
  2. If all expected frequencies ≥ 5 → report chi-square result
  3. If any expected frequency < 5 → use fisher.test() for an exact p-value

See the lecture notes for more detailed explanations and how to conduct Fisher’s exact test in R.

Part 2: Correlation Analysis

What is Correlation?

Correlation analysis tests whether two continuous or ordinal variables have a significant linear (or monotonic) association.


It quantifies both the direction and strength of the relationship:

  • Positive correlation: Both variables increase (or decrease) together
  • Negative correlation: One increases while the other decreases (or vice versa)
  • No correlation: No consistent pattern

The Correlation Coefficient

\[r = \frac{\sum(X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum(X_i - \bar{X})^2} \times \sqrt{\sum(Y_i - \bar{Y})^2}}\]

The Correlation Coefficient

negative correlation

The Correlation Coefficient

no correlation

The Correlation Coefficient Properties

  1. Ranges from -1 to +1
  2. Sign indicates direction
    • r > 0: positive correlation
    • r < 0: negative correlation
    • r = 0: no linear relationship (null hypothesis)
  3. Absolute value indicates strength
|r| Range Strength
|0.00| - |0.19| Very weak or none
|0.20| - |0.39| Weak
|0.40| - |0.59| Moderate
|0.60| - |0.79| Strong
|0.80| - |1.00| Very strong

Pearson vs. Spearman

Pearson Correlation

  • Measures linear relationship
  • For continuous variables
  • Assumes normality
  • Sensitive to outliers

Spearman Correlation

  • Measures monotonic relationship
  • For ordinal variables
  • No normality assumption
  • Robust to outliers

Spearman Correlation

When to Use Spearman

Use Spearman rank correlation when:

  1. Variables are ordinal (ranked data, not truly continuous)
  2. Data has outliers (Spearman uses ranks → less influenced)
  3. Relationship is monotonic but not linear


Spearman converts raw values to ranks, then calculates Pearson correlation on the ranks.

Scenario: Pain Level and Functional Mobility

An orthopedic rehab unit examines the relationship between pain level (0-10 Numeric Rating Scale; higher = more pain) and functional mobility (1-5 Functional Independence Measure; higher = more independent).

Important Limitations

Correlation ≠ Causation

A significant correlation does not mean one variable causes the other.


Always consider:

  • Confounding variables: A third variable causes both
    • e.g., Ice cream sales correlate with drowning deaths —> summer heat drives both
  • Reverse causation: The outcome influences the predictor
    • e.g., Hospitals with more specialists have sicker patients —> but sicker patients are referred to those hospitals
  • Selection bias: Sample selection creates artificial associations
    • e.g., ER-only surveys may show a correlation between flu severity and asthma —> because people with mild flu stay home unless they have asthma complications

Correlation Only Captures Linear Relationships

Code 
workload_nl <- seq(1, 10, length.out = 100)
performance <- -0.5 * (workload_nl - 5.5)^2 + 15 + rnorm(100, 0, 1)
nonlinear_data <- data.frame(workload = workload_nl, performance = performance)
nonlinear_cor <- cor(nonlinear_data$workload, nonlinear_data$performance)

ggplot(nonlinear_data, aes(x = workload, y = performance)) +
  geom_point(alpha = 0.6, color = "steelblue") +
  geom_smooth(method = "lm", se = FALSE, color = "red", linetype = "dashed") +
  geom_smooth(method = "loess", se = FALSE, color = "darkgreen") +
  labs(title = "Non-Linear Relationship with Near-Zero Correlation",
       subtitle = paste("Pearson r =", round(nonlinear_cor, 3), "— but there's clearly a relationship!"),
       x = "Workload Level", y = "Performance Score") +
  theme_minimal() +
  theme(plot.title = element_text(face = "bold"))

A correlation coefficient of zero means no linear relationship. There could still be a strong non-linear pattern.

Pearson is Sensitive to Outliers

A single outlier can create a spurious significant correlation. Always visualize your data!

When outliers are present:

  1. Report Pearson with and without the outlier: check if the result is robust
  2. Use Spearman correlation: ranks are less influenced by extreme values

Summary

Key Takeaways: Method Selection

Variable Types Method R Function Key Statistic
Categorical × Categorical Chi-square test chisq.test() χ²
Continuous × Continuous Pearson correlation cor.test(method="pearson") r
Ordinal × Ordinal Spearman correlation cor.test(method="spearman") ρ

Key Takeaways: Interpretation

  1. Chi-square: Compare observed vs. expected frequencies; p < 0.05 → significant association
  2. Pearson r: Ranges -1 to +1; measures direction and strength of linear relationship
  3. Spearman ρ: Ranges -1 to +1; measures monotonic relationship using ranks
  4. Always remember: Correlation ≠ Causation
