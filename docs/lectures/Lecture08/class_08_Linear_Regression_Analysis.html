Course Context

Data Source: NHANES (National Health and Nutrition Examination Survey)

Research Question: How has BMI changed in the US from 1999-2000 to 2015-2016?

Population: Adults aged 20-59 years

Four Perspectives on Regression

1. Quantifying Association

Purpose: - Summarize relationship between X and Y - One-number summary of how E(Y) changes with X

Key Point: - Association ≠ Causation in observational studies

Example: - How does BMI change per year of age? - Coefficient β₁ = 0.07 - Interpretation: BMI increases by 0.07 units per year of age

2. Explaining Variability

Core Question: How much of the variability in Y is due to X?

  • Left panel: Variability around overall mean E(Y)
  • Right panel: Variability around E(Y|X)

Key Metric: R² (coefficient of determination)

  • R² = 0.70 means 70% of variance explained
  • Use adjusted R² when comparing models

3. Estimating Intervention Effects

Focus on causal effects

Key Challenge: - Observational data ≠ experimental data - Cannot simply interpret β as causal

Requirements: - Control for confounders - Special methods (Chapter 8)

Example: Physical exercise and BMI

  • Simple model: β = -2.15
  • Adjusted for age: β = -1.88
  • Difference due to confounding

4. Predicting Outcomes

Goal: Accurate prediction of future Y values

Key Differences from other perspectives:

  • Focus on predictive accuracy, not explanation
  • May include many variables without scientific rationale
  • Different evaluation criteria
  • Hypothesis testing not appropriate after data-driven selection

The Linear Regression Model

Basic Model Structure

For individual i:

\[Y_i = \beta_0 + \beta_1X_{i1} + \cdots + \beta_kX_{ik} + \epsilon_i\]

Two parts:

  1. Systematic part: \(\beta_0 + \beta_1X_{i1} + \cdots + \beta_kX_{ik}\)
  2. Random part: \(\epsilon_i\)

Model Assumptions

About the systematic part:

  • Linearity: One-unit change in X → constant change in E(Y)
  • Additivity: Effects of Xs combine additively

About the random part (ε):

  1. Normal distribution with mean zero
  2. Constant variance across all sub-populations
  3. Independence between observations

Which Assumptions Matter When?

For valid β estimates: - Correct systematic part - That’s it!

For valid standard errors: - All three assumptions about random part

Important: - Estimates are unbiased even if ε not normal - But SEs, CIs, and p-values may be wrong - Large samples help with normality

Estimation Methods

Least Squares

Objective: Minimize sum of squared differences

\[\text{Minimize: } \sum_{i=1}^n (Y_i - \hat{Y}_i)^2\]

Properties:

  • Does NOT require distributional assumptions
  • Simple computational solution
  • Finds the “closest” line to observed data

Maximum Likelihood

Objective: Find β values that maximize probability of observing the data

Properties:

  • Requires distributional assumptions (normal for linear regression)
  • Provides efficient estimates
  • Valid inference (correct CIs and p-values)

Key Insight: For linear regression with normal errors, least squares = maximum likelihood

Interpreting Coefficients

Basic Interpretation Rules

Intercept (β₀): Mean Y at reference level of all variables

For continuous X: β₁ = change in mean Y for one-unit increase in X, holding all other variables constant

For categorical X: β₁ = difference in mean Y compared to reference level, holding all other variables constant

Example: BMI Model

Interpretation: - BMI increased by 1.47 units from 1999-2000 to 2015-2016 - This is the SAME increase for all age/sex/race groups (additivity assumption)

Coding Considerations

Continuous variables:

  • Is linearity appropriate?
  • What does zero mean? (Consider centering)
  • Should you scale? (e.g., age/10 for 10-year increments)

Categorical variables:

  • What is the reference level?
  • Should categories be combined?

Ordered categorical:

  • Code as continuous or unordered?
  • Risk of dichotomization?

Confounding

What is Confounding?

Definition: Z is a confounder of X→Y association if:

  • Z affects X, AND
  • Z affects Y

Z (AGE) ↙ ↘ X Y

Key Problem: When X changes, Z also changes → difficult to isolate effect of X

Example: Physical Exercise and BMI

Research question: Does physical exercise (PE) reduce BMI?

Unadjusted model: - PE coefficient: -2.15

Adjusted for age: - PE coefficient: -1.88

Interpretation: Part of the “effect” was due to younger people exercising more AND having lower BMI

Controlling for Confounders

In regression models:

  • Include confounders as covariates
  • Interpretation becomes “holding Z constant”
  • Effect of X₂ is estimated comparing sub-populations that differ only in X₂

Important: This is NOT the same as establishing causality!

See Chapter 8 for causal inference methods

Effect Modification (Interaction)

What is Effect Modification?

Definition: The association between X and Y differs across levels of Z

Also called:

  • Moderation
  • Interaction

Example: Does BMI increase over time differ by age group?

Testing for Interaction

Two approaches:

  1. Stratified analysis: Fit separate models for each level of Z
    • Inefficient
    • No formal test
  2. Interaction term: Add X × Z to model
    • More efficient
    • Provides formal test

Interaction Model

\[E(Y) = \beta_0 + \beta_1\text{YEAR} + \beta_2\text{AGE} + \beta_3(\text{AGE} \times \text{YEAR})\]

Interpretation:

  • Change in BMI for younger group: β₁
  • Change in BMI for older group: β₁ + β₃

Critical point: When interaction present, CANNOT interpret main effects alone!

Example: Age-Year Interaction

Results:

  • Younger group: BMI increased 1.64 units
  • Older group: BMI increased 1.64 - 0.49 = 1.15 units
  • Interaction not significant (p = 0.3)

Model Selection

Hypothesis Testing: Single Coefficient

Wald test: Tests H₀: β = 0

\[\text{Test statistic: } \frac{\hat{\beta}}{\text{SE}(\hat{\beta})}\]

  • Compare to normal distribution
  • Requires normality of estimates
  • Valid if Y is normal OR large sample

From output: P-value for each coefficient

Hypothesis Testing: Multiple Coefficients

Likelihood Ratio Test: Compares nested models

  • Restricted model (M₀): Coefficients set to zero
  • Full model (M₁): Coefficients estimated
  • Tests if multiple βs are jointly different from zero

Example: Testing overall effect of RACE variable (4 coefficients)

Equivalent for linear regression: F-test comparing explained variance

Comparing Non-Nested Models

Akaike Information Criterion (AIC): \[\text{AIC} = -2\log[L(M)] + 2k\]

Bayesian Information Criterion (BIC): \[\text{BIC} = -2\log[L(M)] + k\log(n)\]

Where: - L(M) = likelihood of model M - k = number of parameters - n = sample size

Interpretation: LOWER is better (BIC penalizes complexity more)

Model Selection Strategy

Decision tree:

  1. Pre-specified hypothesis? → Use conceptual model to select variables → Classical inference valid

  2. Data-driven selection? → Use AIC/BIC for selection → Classical inference NOT valid → Focus on prediction

Key principle: Match objective → selection method → evaluation criteria

Checking Assumptions

Diagnostic Plots

1. QQ-plot: Check normality of residuals

  • Should show linear trend
  • Large samples: less critical

2. Residuals vs. Fitted: Check constant variance

  • Should show random scatter
  • Funnel shape → non-constant variance

3. Independence: Check study design

  • Repeated measures?
  • Clustering?

What to Do About Violations

Non-normality:

  • Less problematic with large n
  • May still affect inference

Non-constant variance:

  • More serious problem
  • Can invalidate tests
  • Consider transformations or robust SEs

Non-independence:

  • Very serious if ignored
  • Use appropriate methods (Chapter 9)
  • Mixed models, GEE, etc.

Model Adequacy

What Makes a “Good” Model?

Answer: Depends on your objective!

  1. Hypothesis testing: Valid test assumptions
  2. Explaining variability: High R² or R²ₐdⱼ
  3. Causal inference: Control confounding + causal assumptions (Ch 8)
  4. Prediction: High predictive accuracy

No single measure of overall adequacy

R² (Coefficient of Determination)

Definition: Proportion of variance in Y explained by X

\[R^2 = 1 - \frac{\text{Var}_{\text{res}}(M)}{\text{Var}(Y)}\]

Properties:

  • Always increases when adding variables
  • Use adjusted R² for model comparison
  • Low R² doesn’t mean bad model!

BMI example: R² = 4.8% - Age, sex, race, year explain ~5% of BMI variability - Typical for observational studies

Predictive Accuracy

For prediction models:

  • Average squared prediction error
  • Critical: Test on NEW data (external validation)
  • Cross-validation to avoid overfitting

Warning signs of overfitting:

  • Too many predictors
  • Selected on same data being evaluated
  • Good internal, poor external validation

See Chapter 10 for predictive modeling

Extensions of Linear Regression

Quantile Regression

Objective: Model percentiles instead of mean

Use cases:

  • Skewed outcomes
  • Interest in tails of distribution
  • Understanding variability changes

Example: Model 25th and 75th percentiles of BMI

  • Inter-quartile range as function of age
  • Different changes at different percentiles

Non-Parametric Regression

Objective: Relax linearity assumption

Kernel smoothing:

  1. Uniform kernel: Average Y in window around X
  2. Normal kernel: Weighted average (closer = higher weight)

Limitation: Curse of dimensionality

  • Works well for 1-2 variables
  • Difficult with many covariates

Alternative: Generalized Additive Models (GAMs)

Key Takeaways

Critical Concepts

  1. Four objectives require different approaches and evaluation

  2. Coefficient interpretation is conditional on other variables

  3. Confounding is pervasive in observational studies

  4. Interaction means main effects can’t be interpreted alone

  5. Model assumptions matter differently for estimates vs. inference

  6. “Good model” depends entirely on your objective

Common Pitfalls

❌ Interpreting association as causation

❌ Ignoring confounders

❌ Hypothesis testing after data-driven selection

❌ Using R² alone to judge model quality

❌ Forgetting assumptions when doing inference
