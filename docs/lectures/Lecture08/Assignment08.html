Task 3: Spearman Correlation — Triage Acuity and Time to Treatment (3 points)

An emergency department manager wants to examine the relationship between triage acuity level (severity of illness) and time to treatment (the number of minutes from arrival to first clinical intervention). Triage acuity is measured using the Emergency Severity Index (ESI), a 5-level system used in emergency departments to prioritize patients: Level 1 (most acute, life-threatening) through Level 5 (non-urgent, least acute). Because ESI is an ordinal scale (the levels indicate rank order but the intervals between them are not necessarily equal), Spearman correlation is appropriate.

ESI Scale: 1 = Resuscitation, 2 = Emergent, 3 = Urgent, 4 = Less Urgent, 5 = Non-urgent

# Data Loading
ed_triage_data <- read.csv("https://raw.githubusercontent.com/mba642-spring-26/mba642-spring-26.github.io/refs/heads/main/datasets/week08_assignment_data3.csv")
