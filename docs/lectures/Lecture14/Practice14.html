Rating-Based and Choice-Based Methods with R

1 Introduction

1.1 Recap: What is Conjoint Analysis?

Conjoint analysis is a powerful survey-based technique that reveals how people make decisions when facing trade-offs between multiple attributes of a product or service. Instead of simply asking “Do you prefer low prices?” (which always gets a “yes”), conjoint analysis forces respondents to make realistic choices that reveal their true priorities.

The key insight is that people evaluate products and services as bundles of attributes. A health insurance plan isn’t just about the premium—it’s a combination of premium, deductible, network size, and coverage. Conjoint analysis decomposes overall preferences into the contribution of each individual attribute, giving us part-worth utilities that quantify how much each feature matters.

1.2 Two Methods You’ve Learned

In the lecture, you saw two approaches to conjoint analysis:

  1. Rating-Based Conjoint: Respondents rate each profile on a scale (e.g., 1-10). We analyze this using ordinary least squares (OLS) regression to estimate part-worth utilities.

  2. Choice-Based Conjoint: Respondents choose their preferred option from a set of alternatives. We analyze this using multinomial logistic regression (mlogit) to estimate part-worth utilities. This method better mimics real-world decision-making.

Both methods produce the same key outputs: part-worth utilities, attribute importance scores, willingness-to-pay estimates, and market share predictions.

# Create full factorial design for clinic profiles
clinic_profiles <- expand.grid(
  distance_5min = c(1, 0),     # 1 = 5 min, 0 = 25 min
  wait_sameweek = c(1, 0),     # 1 = Same-week, 0 = 3 weeks
  provider_md = c(1, 0),        # 1 = MD, 0 = NP
  copay = c(25, 50)
)
clinic_profiles$profile_id <- 1:nrow(clinic_profiles)

# Simulate choice data from 100 respondents
n_respondents <- 100
n_choice_sets <- 8

choice_clinic <- data.frame()

for (resp in 1:n_respondents) {
  for (cs in 1:n_choice_sets) {
    # Randomly select two different profiles
    profiles <- sample(1:16, 2)

    alt_A <- clinic_profiles[profiles[1], ]
    alt_B <- clinic_profiles[profiles[2], ]

    # Calculate utilities (true preferences for simulation)
    # Distance: +2.5 for nearby clinic
    # Wait: +3.0 for same-week appointments
    # Provider: +1.0 for MD
    # Copay: -0.08 per dollar
    utility_A <- 2.5 * alt_A$distance_5min +
                 3.0 * alt_A$wait_sameweek +
                 1.0 * alt_A$provider_md +
                 -0.08 * alt_A$copay +
                 rnorm(1, 0, 0.5)

    utility_B <- 2.5 * alt_B$distance_5min +
                 3.0 * alt_B$wait_sameweek +
                 1.0 * alt_B$provider_md +
                 -0.08 * alt_B$copay +
                 rnorm(1, 0, 0.5)

    choice_A <- as.integer(utility_A > utility_B)

    choice_clinic <- rbind(choice_clinic, data.frame(
      respondent_id = resp,
      choice_set = cs,
      distance_5min_A = alt_A$distance_5min,
      wait_sameweek_A = alt_A$wait_sameweek,
      provider_md_A = alt_A$provider_md,
      copay_A = alt_A$copay,
      distance_5min_B = alt_B$distance_5min,
      wait_sameweek_B = alt_B$wait_sameweek,
      provider_md_B = alt_B$provider_md,
      copay_B = alt_B$copay,
      choice_A = choice_A
    ))
  }
}

2.2.4 Task 1: Reshape Data to Long Format

Choice-based conjoint requires data in “long format” where each alternative gets its own row.

library(tidyr)

# Create unique choice set IDs
choice_clinic <- choice_clinic %>%
  mutate(choice_set_id = paste0(respondent_id, "_", choice_set))

# Reshape from wide to long format
clinic_long <- choice_clinic %>%
  pivot_longer(
    cols = c(distance_5min_A, distance_5min_B,
             wait_sameweek_A, wait_sameweek_B,
             provider_md_A, provider_md_B,
             copay_A, copay_B),
    names_to = c(".value", "alternative"),
    names_pattern = "(.*)_([AB])$"  # Match everything before the final _A or _B
  ) %>%
  mutate(
    # Create the choice variable (1 = chosen, 0 = not chosen)
    # Logic: If alternative A was chosen (choice_A = 1):
    #   - Row for alternative A gets choice = 1
    #   - Row for alternative B gets choice = 0
    # If alternative B was chosen (choice_A = 0):
    #   - Row for alternative A gets choice = 0
    #   - Row for alternative B gets choice = 1
    choice = case_when(
      alternative == "A" & choice_A == 1 ~ ___,
      alternative == "A" & choice_A == 0 ~ ___,
      alternative == "B" & choice_A == 1 ~ ___,
      alternative == "B" & choice_A == 0 ~ ___
    )
  ) %>%
  select(choice_set = choice_set_id, alternative,
         distance_5min, wait_sameweek, provider_md, copay, choice) %>%
  arrange(choice_set, alternative) %>%
  as.data.frame()

2.2.9 Task 6: Predict Market Share

Compare two competing clinics using the multinomial logit formula.

# Define two competing clinics
# Clinic A: Near (5 min), Same-week, NP, $50 copay
# Clinic B: Far (25 min), 3-week wait, MD, $25 copay

# Calculate systematic utilities
utility_A_clinic <- coef_clinic["distance_5min"] * 1 +
                    coef_clinic["wait_sameweek"] * 1 +
                    coef_clinic["provider_md"] * 0 +
                    coef_clinic["copay"] * 50

utility_B_clinic <- coef_clinic["distance_5min"] * 0 +
                    coef_clinic["wait_sameweek"] * 0 +
                    coef_clinic["provider_md"] * 1 +
                    coef_clinic["copay"] * 25

# Apply multinomial logit formula
share_A_clinic <- _____ / (exp(utility_A_clinic) + exp(utility_B_clinic))
share_B_clinic <- _____ / (exp(utility_A_clinic) + exp(utility_B_clinic))

# Display results
cat("Clinic A (Convenient, NP, Higher copay): ", round(share_A_clinic * 100, 1), "%\n")
cat("Clinic B (Far, MD, Lower copay): ", round(share_B_clinic * 100, 1), "%\n")

Hint: Fill in the numerators using the multinomial logit formula. The probability of choosing alternative i is exp(U_i) divided by the sum of exp(U_j) for all alternatives.
