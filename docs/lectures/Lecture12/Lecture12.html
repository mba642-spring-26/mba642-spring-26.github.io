1 Introduction

1.1 Moving Beyond Continuous Predictors

In Part 1, we focused primarily on continuous predictors (e.g., age, severity scores). However, many important variables in healthcare are categorical:

  • Hospital type: Teaching vs. Community vs. Critical Access
  • Insurance type: Medicare, Medicaid, Private, Uninsured
  • Treatment protocol: Standard Care vs. Enhanced Recovery
  • Region: Northeast, South, Midwest, West

This section covers two essential extensions to linear regression:

  1. Dummy Variables: How to include categorical predictors in regression
  2. Interaction Effects: When the effect of one variable depends on another

1.2 Why This Matters for Healthcare Managers

Understanding these techniques allows you to:

  • Compare outcomes across hospital types or treatment groups
  • Determine if an intervention works differently for different patient populations
  • Make evidence-based decisions about resource allocation across categories
  • Design targeted interventions for specific subgroups

2 Dummy Variables (Indicator Variables)

2.1 The Challenge with Categorical Variables

Regression requires numerical inputs, but categorical variables are not inherently numerical. Simply assigning numbers (1, 2, 3) to categories implies an ordering and equal spacing that usually doesn’t exist.

Solution: Create dummy variables (also called indicator variables) that represent category membership using 0s and 1s.

2.2 Binary Categorical Variables

For a variable with two categories, we need one dummy variable:

Patient Insurance Status Dummy: Insured
1 Insured 1
2 Uninsured 0
3 Insured 1
4 Uninsured 0

Interpretation: The coefficient on the dummy variable represents the difference in the outcome between the two groups.

2.2.1 Healthcare Example: Treatment Protocol Comparison

Let’s compare patient outcomes between a standard care protocol and an enhanced recovery after surgery (ERAS) protocol.

# Generate surgical patient data
n <- 200

surgical_data <- tibble(
  patient_id = 1:n,
  protocol = sample(c("Standard", "ERAS"), n, replace = TRUE),
  age = round(rnorm(n, 62, 12)),
  bmi = round(rnorm(n, 28, 5), 1),
  surgery_complexity = sample(1:3, n, replace = TRUE)  # 1=Low, 2=Medium, 3=High
) %>%
  mutate(
    age = pmax(30, pmin(age, 85)),

2.3 Multi-Level Categorical Variables

When a categorical variable has more than two levels, we need k-1 dummy variables (where k is the number of categories).

2.3.1 Why k-1 and Not k?

Including a dummy for every category would create perfect multicollinearity (the dummy variables would sum to 1 for every observation, which is perfectly correlated with the intercept).

2.3.2 Healthcare Example: Hospital Type Comparison

Let’s examine how hospital type affects 30-day readmission rates.

# Generate hospital data
n_hospitals <- 250

hospital_type_data <- tibble(
  hospital_id = 1:n_hospitals,
  hospital_type = sample(c("Teaching", "Community", "Critical Access"),
                        n_hospitals, replace = TRUE,
                        prob = c(0.25, 0.50, 0.25)),
  bed_count = case_when(
    hospital_type == "Teaching" ~ round(rnorm(n_hospitals, 400, 100)),
    hospital_type == "Community" ~ round(rnorm(n_hospitals, 200, 80)),
    hospital_type == "Critical Access" ~ round(rnorm(n_hospitals, 40, 15))
  ),

  nurse_per_patient = round(runif(n_hospitals, 2, 5), 2)
) %>%
  mutate(
    bed_count = pmax(10, bed_count),

      15 +
      2.5 * avg_patient_severity +
      -0.8 * nurse_per_patient +

        hospital_type == "Teaching" ~ -2.5,       # Reference in effect
        hospital_type == "Community" ~ 0,
        hospital_type == "Critical Access" ~ 3.0

      rnorm(n_hospitals, 0, 2),
      1

                          levels = c("Community", "Teaching", "Critical Access"))
  )

3 Interaction Effects

3.1 What Are Interactions?

An interaction effect occurs when the effect of one variable on the outcome depends on the value of another variable.

Without interaction: \[Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \epsilon\]

With interaction: \[Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \beta_3 (X_1 \times X_2) + \epsilon\]

The interaction term \(\beta_3\) captures how the effect of \(X_1\) changes across levels of \(X_2\) (and vice versa).

3.2 Why Interactions Matter in Healthcare

Many healthcare relationships are conditional:

  • Treatment effectiveness varies by patient characteristics: A medication may work better for younger patients
  • Resource effects depend on hospital type: Additional staffing may have different impacts in teaching vs. community hospitals
  • Policy impacts vary by region: A new payment model may affect urban and rural hospitals differently

3.3 Continuous × Categorical Interaction

3.3.1 Healthcare Example: Does Staffing Effect Vary by Hospital Type?

Let’s test whether the effect of nurse staffing on patient satisfaction varies by hospital ownership type (for-profit vs. non-profit).

# Generate data for interaction example
n <- 300

satisfaction_data <- tibble(
  hospital_id = 1:n,
  ownership = sample(c("For-Profit", "Non-Profit"), n, replace = TRUE),
  nurse_ratio = round(runif(n, 2, 6), 2),
  patient_volume = round(rnorm(n, 500, 150)),
  avg_acuity = round(runif(n, 1, 3), 2)
) %>%
  mutate(
    patient_volume = pmax(100, patient_volume),
    # Interaction: staffing matters more in non-profit hospitals
    patient_satisfaction = round(
      50 +
      3 * nurse_ratio +                              # Base staffing effect
      5 * (ownership == "Non-Profit") +              # Non-profit baseline higher
      2.5 * nurse_ratio * (ownership == "Non-Profit") + # INTERACTION
      -0.01 * patient_volume +
      -3 * avg_acuity +
      rnorm(n, 0, 5),
      1
    ),
    patient_satisfaction = pmax(0, pmin(patient_satisfaction, 100)),
    ownership = factor(ownership, levels = c("For-Profit", "Non-Profit"))
  )

# Model WITHOUT interaction (main effects only)

3.4 Categorical × Categorical Interaction

Interactions can also occur between two categorical variables.

3.4.1 Healthcare Example: Treatment Effect Varies by Insurance Type

Does the effectiveness of a diabetes management program differ by patient insurance type?

# Generate data
n <- 400

diabetes_data <- tibble(
  patient_id = 1:n,
  treatment = sample(c("Standard Care", "Intensive Program"), n, replace = TRUE),
  insurance = sample(c("Medicare", "Medicaid", "Private"), n, replace = TRUE,
                    prob = c(0.4, 0.3, 0.3)),
  baseline_a1c = round(rnorm(n, 8.5, 1.2), 1),
  age = round(rnorm(n, 60, 12))
) %>%
  mutate(
    baseline_a1c = pmax(6, pmin(baseline_a1c, 12)),
    age = pmax(30, pmin(age, 85)),
    # Generate A1c reduction with interaction
    a1c_reduction = round(
      0.5 +
      0.3 * (treatment == "Intensive Program") +   # Base treatment effect
      0.2 * (insurance == "Private") +              # Private insurance effect
      0.1 * (insurance == "Medicare") +
      # Interactions: treatment works better with Private insurance
      0.8 * (treatment == "Intensive Program") * (insurance == "Private") +
      0.3 * (treatment == "Intensive Program") * (insurance == "Medicare") +
      0.05 * baseline_a1c +
      rnorm(n, 0, 0.4),
      2
    ),
    a1c_reduction = pmax(0, a1c_reduction),
    treatment = factor(treatment, levels = c("Standard Care", "Intensive Program")),
    insurance = factor(insurance, levels = c("Medicaid", "Medicare", "Private"))
  )

4 Practical Considerations

4.1 When to Include Interactions

Include interactions when:

  1. Theory or prior research suggests the effect should vary
  2. Visual inspection shows different slopes for different groups
  3. You have sufficient sample size (interactions require larger samples)

Avoid over-fitting: Don’t include interactions just to “improve R².” Only include interactions with theoretical justification.

4.2 Centering Variables

For models with interactions, centering continuous variables (subtracting the mean) improves interpretability:

Interactions require larger sample sizes because:

  • They partition the data into subgroups
  • They add parameters to estimate
  • They can have smaller effect sizes

Rule of thumb: Have at least 15-20 observations per combination of categorical variables involved in the interaction.

6 Summary

6.1 Key Takeaways

6.1.1 Dummy Variables

  • Represent categorical variables using 0/1 indicator variables
  • For k categories, create k-1 dummy variables
  • Coefficients represent differences from the reference category
  • Change reference category with relevel() to make different comparisons

6.1.2 Interaction Effects

  • Occur when the effect of one variable depends on another variable
  • Include interaction term: X1 * X2 or X1:X2
  • Test significance by comparing models with and without interaction
  • Main effects change meaning when interaction is present

6.1.3 Interpretation Guidelines

For interactions between continuous (X) and categorical (Z) variables:

  • Main effect of X: Effect of X when Z = reference category
  • Main effect of Z: Effect of Z when X = 0 (or mean if centered)
  • Interaction: How much the effect of X changes for other levels of Z

For interactions between two categorical variables:

  • Use marginal means to compare all combinations
  • Visualize with grouped bar charts or interaction plots

6.1.4 Healthcare Applications

  • Compare outcomes across hospital types, regions, or treatment groups
  • Test whether interventions work differently for different populations
  • Identify which patient subgroups benefit most from specific treatments
  • Understand how organizational characteristics moderate the effects of investments

6.2 Best Practices

  1. Visualize before modeling - Look for different slopes or patterns
  2. Have theoretical justification - Don’t fish for interactions
  3. Center continuous variables - Improves interpretability
  4. Check sample sizes - Need adequate observations per subgroup
  5. Report results clearly - Calculate simple slopes, create visualizations

# Introduction

## Moving Beyond Continuous Predictors

In Part 1, we focused primarily on continuous predictors (e.g., age, severity scores). However, many important variables in healthcare are **categorical**:

- **Hospital type**: Teaching vs. Community vs. Critical Access
- **Insurance type**: Medicare, Medicaid, Private, Uninsured
- **Treatment protocol**: Standard Care vs. Enhanced Recovery
- **Region**: Northeast, South, Midwest, West

This section covers two essential extensions to linear regression:

1. **Dummy Variables**: How to include categorical predictors in regression
2. **Interaction Effects**: When the effect of one variable depends on another

## Why This Matters for Healthcare Managers

Understanding these techniques allows you to:

- Compare outcomes across hospital types or treatment groups
- Determine if an intervention works differently for different patient populations
- Make evidence-based decisions about resource allocation across categories
- Design targeted interventions for specific subgroups

# Dummy Variables (Indicator Variables)

## The Challenge with Categorical Variables

Regression requires numerical inputs, but categorical variables are not inherently numerical. Simply assigning numbers (1, 2, 3) to categories implies an ordering and equal spacing that usually doesn't exist.

**Solution**: Create **dummy variables** (also called indicator variables) that represent category membership using 0s and 1s.

## Binary Categorical Variables

For a variable with **two categories**, we need **one dummy variable**:

| Patient | Insurance Status | Dummy: Insured |
|---------|-----------------|----------------|
| 1 | Insured | 1 |
| 2 | Uninsured | 0 |
| 3 | Insured | 1 |
| 4 | Uninsured | 0 |

**Interpretation**: The coefficient on the dummy variable represents the difference in the outcome between the two groups.

## Multi-Level Categorical Variables

When a categorical variable has **more than two levels**, we need **k-1 dummy variables** (where k is the number of categories).

### Why k-1 and Not k?

Including a dummy for every category would create **perfect multicollinearity** (the dummy variables would sum to 1 for every observation, which is perfectly correlated with the intercept).

# Interaction Effects

## What Are Interactions?

An **interaction effect** occurs when the effect of one variable on the outcome **depends on the value of another variable**.

Without interaction:
$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \epsilon$$

With interaction:
$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \beta_3 (X_1 \times X_2) + \epsilon$$

The interaction term $\beta_3$ captures how the effect of $X_1$ changes across levels of $X_2$ (and vice versa).

## Why Interactions Matter in Healthcare

Many healthcare relationships are conditional:

- **Treatment effectiveness varies by patient characteristics**: A medication may work better for younger patients
- **Resource effects depend on hospital type**: Additional staffing may have different impacts in teaching vs. community hospitals
- **Policy impacts vary by region**: A new payment model may affect urban and rural hospitals differently

## Continuous × Categorical Interaction

### Healthcare Example: Does Staffing Effect Vary by Hospital Type?

Let's test whether the effect of nurse staffing on patient satisfaction varies by hospital ownership type (for-profit vs. non-profit).

```{r}
#| label: interaction-data

# Generate data for interaction example
n <- 300

satisfaction_data <- tibble(
  hospital_id = 1:n,
  ownership = sample(c("For-Profit", "Non-Profit"), n, replace = TRUE),
  nurse_ratio = round(runif(n, 2, 6), 2),
  patient_volume = round(rnorm(n, 500, 150)),
  avg_acuity = round(runif(n, 1, 3), 2)
) %>%
  mutate(
    patient_volume = pmax(100, patient_volume),
    # Interaction: staffing matters more in non-profit hospitals
    patient_satisfaction = round(
      50 +
      3 * nurse_ratio +                              # Base staffing effect
      5 * (ownership == "Non-Profit") +              # Non-profit baseline higher
      2.5 * nurse_ratio * (ownership == "Non-Profit") + # INTERACTION
      -0.01 * patient_volume +
      -3 * avg_acuity +
      rnorm(n, 0, 5),
```

**Understanding the Coefficients**:

```{r}
#| echo: false
int_coefs <- coef(model_interact)
```

1. **nurse_ratio (`r round(int_coefs["nurse_ratio"], 2)`)**: The effect of staffing on satisfaction **for the reference group (For-Profit hospitals)**. Each additional nurse per patient increases satisfaction by `r round(int_coefs["nurse_ratio"], 2)` points.

2. **ownershipNon-Profit (`r round(int_coefs["ownershipNon-Profit"], 2)`)**: The difference in satisfaction between Non-Profit and For-Profit hospitals **when nurse_ratio = 0** (not meaningful here, but mathematically necessary).

3. **nurse_ratio:ownershipNon-Profit (`r round(int_coefs["nurse_ratio:ownershipNon-Profit"], 2)`)**: **THE INTERACTION TERM**. This is the additional effect of staffing in Non-Profit hospitals beyond the effect in For-Profit hospitals.

**Computing the Effect of Staffing for Each Group**:

- **For-Profit**: β = `r round(int_coefs["nurse_ratio"], 2)`
- **Non-Profit**: β = `r round(int_coefs["nurse_ratio"], 2)` + `r round(int_coefs["nurse_ratio:ownershipNon-Profit"], 2)` = `r round(int_coefs["nurse_ratio"] + int_coefs["nurse_ratio:ownershipNon-Profit"], 2)`

**Interpretation**: Nurse staffing has a significantly stronger positive effect on patient satisfaction in Non-Profit hospitals compared to For-Profit hospitals.

## Continuous × Continuous Interaction

Interactions can also occur between two continuous variables.

### Healthcare Example: Age Moderates Treatment Duration Effect

Does the benefit of longer physical therapy duration depend on patient age?

```{r}

  patient_id = 1:n,
  pt_sessions = round(runif(n, 4, 24)),
  age = round(runif(n, 25, 80)),
  baseline_function = round(runif(n, 30, 70))
) %>%
  mutate(

      5 +
      1.2 * pt_sessions +
```

# Practical Considerations

## When to Include Interactions

**Include interactions when**:

1. Theory or prior research suggests the effect should vary
2. Visual inspection shows different slopes for different groups
3. You have sufficient sample size (interactions require larger samples)

**Avoid over-fitting**: Don't include interactions just to "improve R²." Only include interactions with theoretical justification.

## Centering Variables

For models with interactions, **centering** continuous variables (subtracting the mean) improves interpretability:

```{r}
#| label: centering

# Center variables
satisfaction_data <- satisfaction_data %>%
  mutate(
    nurse_ratio_c = nurse_ratio - mean(nurse_ratio),
    patient_volume_c = patient_volume - mean(patient_volume)
  )

# Model with centered variables
model_centered <- lm(patient_satisfaction ~ nurse_ratio_c * ownership +
                     patient_volume_c + avg_acuity, data = satisfaction_data)

tidy(model_centered) %>%
  mutate(across(where(is.numeric), ~round(., 3))) %>%
  kable(caption = "Model with Centered Variables") %>%
  kable_styling(bootstrap_options = c("striped", "hover"))
```

**Benefit**: After centering, the main effect coefficients represent the effect **at the mean of the other variable**, which is often more meaningful than "when the other variable = 0."

## Sample Size Requirements

Interactions require larger sample sizes because:

- They partition the data into subgroups
- They add parameters to estimate
- They can have smaller effect sizes

**Rule of thumb**: Have at least 15-20 observations per combination of categorical variables involved in the interaction.

# Summary

## Key Takeaways

### Dummy Variables

- Represent categorical variables using 0/1 indicator variables
- For k categories, create k-1 dummy variables
- Coefficients represent differences from the **reference category**
- Change reference category with `relevel()` to make different comparisons

### Interaction Effects

- Occur when the effect of one variable depends on another variable
- Include interaction term: `X1 * X2` or `X1:X2`
- Test significance by comparing models with and without interaction
- **Main effects change meaning** when interaction is present

### Interpretation Guidelines

**For interactions between continuous (X) and categorical (Z) variables**:

- Main effect of X: Effect of X when Z = reference category
- Main effect of Z: Effect of Z when X = 0 (or mean if centered)
- Interaction: How much the effect of X changes for other levels of Z

**For interactions between two categorical variables**:

- Use marginal means to compare all combinations
- Visualize with grouped bar charts or interaction plots

### Healthcare Applications

- Compare outcomes across hospital types, regions, or treatment groups
- Test whether interventions work differently for different populations
- Identify which patient subgroups benefit most from specific treatments
- Understand how organizational characteristics moderate the effects of investments

## Best Practices

1. **Visualize before modeling** - Look for different slopes or patterns
2. **Have theoretical justification** - Don't fish for interactions
3. **Center continuous variables** - Improves interpretability
4. **Check sample sizes** - Need adequate observations per subgroup
5. **Report results clearly** - Calculate simple slopes, create visualizations
