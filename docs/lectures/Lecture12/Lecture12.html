1 Introduction

1.1 Moving Beyond Continuous Predictors

In our last lecture, we focused primarily on continuous predictors (e.g., age, severity scores) in linear regression. However, many important variables in healthcare research are categorical:

  • Hospital type: Teaching vs. Community vs. Critical Access
  • Insurance type: Medicare, Medicaid, Private, Uninsured
  • Treatment protocol: Standard Care vs. Enhanced Recovery
  • Region: Northeast, South, Midwest, West

This section covers two essential extensions to linear regression:

  1. Dummy Variables: How to handle and include categorical predictors in regression
  2. Interaction Effects: Whether the effect of one variable depends on another

1.2 Why This Matters

Understanding these techniques allows you to:

  • Compare outcomes across hospital types or treatment groups
  • Determine if an intervention works differently for different patient populations
  • Make evidence-based decisions about resource allocation across categories
  • Design targeted interventions for specific subgroups

2 Dummy Variables (Indicator Variables)

2.1 What is it?

Dummy variables (also called indicator variables) are binary variables that represent categorical group membership using 0s and 1s. They allow us to include categorical predictors in regression models, which mathematically require numerical inputs.

For a categorical variable with k categories, we create k-1 dummy variables, with one category serving as the reference group against which all others are compared.

For example, if we have a variable “Hospital Type” with three categories (Teaching, Community, Critical Access), we would create two dummy variables:

  • Dummy 1: Teaching (1 if Teaching, 0 otherwise)
  • Dummy 2: Critical Access (1 if Critical Access, 0 otherwise)

Community hospitals would be the reference category (both dummies = 0).

Dummy 1 captures the difference between Teaching and Community hospitals (the reference category), while Dummy 2 captures the difference between Critical Access and Community hospitals.

2.2 When to Use It

Use dummy variables when you need to:

  • Include categorical predictors in regression (hospital type, insurance status, treatment group)
  • Compare outcomes across different categories while controlling for other variables
  • Test whether group differences are statistically significant
  • Quantify the magnitude of differences between categories

2.3 The Challenge with Categorical Variables

Regression requires numerical inputs, but categorical variables are not inherently numerical. Simply assigning numbers (1, 2, 3) to categories implies an ordering and equal spacing that usually doesn’t exist.

Solution: Create dummy variables that represent category membership using 0s and 1s.

2.4 Binary Categorical Variables

For a variable with two categories, we need one dummy variable:

Patient Insurance Status Dummy: Insured
1 Insured 1
2 Uninsured 0
3 Insured 1
4 Uninsured 0

The coefficient on the dummy variable (Insured) represents the difference in the outcome between the two groups (Insured vs. Uninsured).

2.4.1 Dummy Variable Example Case: Treatment Protocol Comparison

2.4.1.1 Background and Context

The problem: Traditional surgical recovery involves extended hospital stays, which are costly and can lead to complications.

A better approach: Enhanced Recovery After Surgery (ERAS) protocols use evidence-based practices to help patients recover faster. These include:

  • Better pain management (using less opioid medication)
  • Getting patients moving sooner after surgery
  • Starting normal eating earlier

Research evidence: A 2025 study found that ERAS protocols significantly reduce hospital length of stay compared to traditional care, with patients recovering and being discharged substantially earlier.

Let’s compare patient outcomes between standard care and ERAS protocols to quantify the treatment effect using a dummy variable.

2.4.1.2 Creating Synthetic Healthcare Data

We’ll create a dataset with 200 surgical patients that includes:

Variables in the dataset:

  • patient_id: Unique identifier for each patient (1 to 200)
  • protocol: Treatment protocol assigned (Standard or ERAS)
  • age: Patient age in years
  • bmi: Body Mass Index (measure of body fat based on height and weight)
  • surgery_complexity: Complexity level of the surgery (1 = Low, 2 = Medium, 3 = High)
  • length_of_stay: Hospital length of stay in days (our outcome variable)

Let’s create the dataset using the code below:

# Generate surgical patient data
n <- 200

surgical_data <- tibble(
  patient_id = 1:n,
  protocol = sample(c("Standard", "ERAS"), n, replace = TRUE),
  age = round(rnorm(n, 62, 12)),
  bmi = round(rnorm(n, 28, 5), 1),
  surgery_complexity = sample(1:3, n, replace = TRUE)  # 1=Low, 2=Medium, 3=High
) %>%
  mutate(
    age = pmax(30, pmin(age, 85)),
    bmi = pmax(18, pmin(bmi, 45)),
    # ERAS reduces LOS
    length_of_stay = round(
      3 +
      0.03 * age +
      0.05 * bmi +
      1.5 * surgery_complexity +
      -1.8 * (protocol == "ERAS") +  # ERAS effect
      rnorm(n, 0, 1),
      1
    ),
    length_of_stay = pmax(1, length_of_stay)
  )

# Summary by protocol
surgical_data %>%
  group_by(protocol) %>%
  summarise(
    n = n(),
    mean_los = round(mean(length_of_stay), 2),
    sd_los = round(sd(length_of_stay), 2),
    min_los = min(length_of_stay),
    max_los = max(length_of_stay)
  ) %>%
  kable(caption = "Length of Stay by Treatment Protocol") %>%
  kable_styling(bootstrap_options = c("striped", "hover"))

The variable protocol is our binary categorical variable (Standard vs. ERAS). We’ll create a dummy variable for ERAS (1 = ERAS, 0 = Standard) to include in our regression model.

We can do this using the factor() function in R, which automatically creates the necessary dummy variable.

# R automatically creates dummy variables for factors
surgical_data <- surgical_data %>%
  mutate(protocol = factor(protocol, levels = c("Standard", "ERAS")))

                     data = surgical_data)

# Extract coefficients

2.4.4 Manual Calculation with Dummy Variables

Let’s manually calculate predicted length of stay to understand how dummy variables work in the regression equation.

The fitted equation is:

\(\widehat{\text{LOS}} = \beta_0 + \beta_1(\text{ERAS}) + \beta_2(\text{Age}) + \beta_3(\text{BMI}) + \beta_4(\text{Complexity})\)

where ERAS is a dummy variable:

  • ERAS = 0 for Standard protocol
  • ERAS = 1 for ERAS protocol

With the fitted coefficients, this becomes:

\(\widehat{\text{LOS}} = 3.218 + -1.788(\text{ERAS}) + 0.027(\text{Age}) + 0.048(\text{BMI}) + 1.497(\text{Complexity})\)

Let’s get predicted LOS for both protocols for a patient who is 65 years old, has a BMI of 30, and underwent a medium complexity surgery (complexity = 2).

# get coefficients
coefs <- tidy(model_protocol, conf.int = TRUE)

# Example patient: 65 years old, BMI 30, complexity=2
age_val <- 65
bmi_val <- 30
complexity_val <- 2

# Scenario 1: Standard protocol (dummy = 0)
pred_standard <- coeffs[1] +                    # Intercept
                 0 * coeffs[2] +                # protocolERAS = 0
                 age_val * coeffs[3] +          # Age effect
                 bmi_val * coeffs[4] +          # BMI effect
                 complexity_val * coeffs[5]     # Complexity effect

cat("Predicted LOS (Standard protocol):", round(pred_standard, 2), "days\n")

2.5 Multi-Level Categorical Variables

When a categorical variable has more than two levels, we need k-1 dummy variables (where k is the number of categories).

2.5.1 Why k-1 and Not k?

Including a dummy for every category would create perfect multicollinearity (the dummy variables would sum to 1 for every observation, which is perfectly correlated with the intercept).

2.5.2 Multi-Level Categorical Variables Example: Hospital Type Comparison

2.5.2.1 Background and Context

The context: Hospitals come in different types:

  • Teaching hospitals: Large academic medical centers that train medical residents and handle complex cases
  • Community hospitals: General hospitals serving local populations
  • Critical Access hospitals: Small rural hospitals in remote areas with limited resources

Question: Do 30-day readmission rates (the percentage of patients who return to the hospital within 30 days) differ across these hospital types?

  • A 2017 study examining nearly 4,500 U.S. hospitals found that readmission rates vary by hospital type, reflecting differences in patient complexity, resources, and care patterns.

Let’s compare 30-day readmission rates across three hospital types while controlling for patient characteristics and staffing levels using dummy variables.

2.5.2.2 Creating Synthetic Healthcare Data

Let’s create a dataset using the code below:

# Generate hospital data
n_hospitals <- 250

hospital_type_data <- tibble(
  hospital_id = 1:n_hospitals,
  hospital_type = sample(c("Teaching", "Community", "Critical Access"),
                        n_hospitals, replace = TRUE,
                        prob = c(0.25, 0.50, 0.25)),
  bed_count = case_when(
    hospital_type == "Teaching" ~ round(rnorm(n_hospitals, 400, 100)),
    hospital_type == "Community" ~ round(rnorm(n_hospitals, 200, 80)),
    hospital_type == "Critical Access" ~ round(rnorm(n_hospitals, 40, 15))
  ),
  avg_patient_severity = round(runif(n_hospitals, 1, 3), 2),
  nurse_per_patient = round(runif(n_hospitals, 2, 5), 2)
) %>%
  mutate(
    bed_count = pmax(10, bed_count),
    # Generate readmission rate
    readmission_rate = round(
      15 +
      2.5 * avg_patient_severity +
      -0.8 * nurse_per_patient +
      case_when(
        hospital_type == "Teaching" ~ -2.5,       # Reference in effect
        hospital_type == "Community" ~ 0,
        hospital_type == "Critical Access" ~ 3.0
      ) +
      rnorm(n_hospitals, 0, 2),
      1
    ),
    readmission_rate = pmax(5, pmin(readmission_rate, 30))
  )

# Summary by hospital type
hospital_type_data %>%
  group_by(hospital_type) %>%
  summarise(
    n = n(),
    mean_readmission = round(mean(readmission_rate), 2),
    sd_readmission = round(sd(readmission_rate), 2)
  ) %>%
  kable(caption = "Readmission Rates by Hospital Type") %>%
  kable_styling(bootstrap_options = c("striped", "hover"))

2.5.5 Testing Comparisons Between Non-Reference Categories

The regression output provides p-values for comparisons against the reference category (Community hospitals), but what about comparing Teaching vs. Critical Access hospitals directly?

We need to test whether the linear combination of coefficients is statistically significant. We can use the emmeans() function with the pairs() function for pairwise comparisons.

# Calculate estimated marginal means
emm <- emmeans(model_hospital, "hospital_type")

# Pairwise comparisons with adjustment for multiple testing
pairs(emm)
 contrast                    estimate    SE  df t.ratio p.value
 Community - Teaching            1.95 0.289 245   6.738  <.0001
 Community - Critical Access    -2.68 0.296 245  -9.038  <.0001
 Teaching - Critical Access     -4.63 0.338 245 -13.694  <.0001

P value adjustment: tukey method for comparing a family of 3 estimates

This provides all pairwise comparisons with confidence intervals and p-values:

  • Teaching vs. Community
  • Critical Access vs. Community
  • Teaching vs. Critical Access (this is what we want!)

The emmeans approach is particularly useful because it:

  1. Shows all pairwise comparisons at once
  2. Adjusts p-values for multiple testing (using Tukey method by default)
  3. Provides confidence intervals for the differences

Based on these tests, we can conclude whether Teaching hospitals have statistically significantly lower readmission rates than Critical Access hospitals, not just numerically lower rates.

3 Interaction Effects

3.1 What is it?

An interaction effect occurs when the effect of one variable on the outcome depends on the value of another variable. In other words, the relationship between X₁ and Y changes across different levels of X₂.

Mathematically, we add an interaction term that is the product of the two variables:

\[Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \beta_3 (X_1 \times X_2) + \epsilon\]

The interaction coefficient \(\beta_3\) captures how the effect of \(X_1\) changes across levels of \(X_2\) (and vice versa).

3.2 When to Use It

Use interaction terms when:

  • Theory or prior research suggests an effect should vary across groups
  • You observe different slopes for different groups in exploratory visualizations
  • You want to test whether an intervention works differently for different populations

3.3 Why Interactions Matter in Healthcare

Many healthcare relationships are conditional. For example:

  • Treatment effectiveness varies by patient characteristics: A medication may work better for younger patients compared to older patients
  • Resource effects depend on hospital type: Additional staffing may have different impacts in big vs. small hospitals
  • Policy impacts vary by region: A new payment model may affect urban and rural hospitals differently

3.4 Continuous × Categorical Interaction

3.4.1 Continuous × Categorical Interaction Example: Does Staffing Effect Vary by Hospital Type?

3.4.1.1 Background and Context

Question: Does improving nurse staffing increase patient satisfaction equally in all hospitals?

Why it might differ: Hospitals have different ownership structures:

  • For-Profit hospitals: Owned by investors, focused on financial performance
  • Non-Profit hospitals: Community-owned, mission-driven, may reinvest more in quality

The hypothesis: Additional nurses might have a bigger impact on satisfaction in non-profit hospitals if they have stronger cultures of patient-centered care.

  • Studies have found that nurse staffing levels significantly affect patient outcomes and satisfaction, though the magnitude of these effects may vary by hospital characteristics including ownership type.

Let’s test whether the effect of nurse staffing on patient satisfaction varies by ownership type (this is a continuous (staffing) × categorical (hospital type) interaction).

3.4.1.2 Creating Synthetic Healthcare Data

Let’s create a dataset using the code below.

# Generate data for interaction example
n <- 300

satisfaction_data <- tibble(
  hospital_id = 1:n,
  ownership = sample(c("For-Profit", "Non-Profit"), n, replace = TRUE),
  nurse_ratio = round(runif(n, 2, 6), 2),
  patient_volume = round(rnorm(n, 500, 150)),
  avg_acuity = round(runif(n, 1, 3), 2)
) %>%
  mutate(
    patient_volume = pmax(100, patient_volume),
    # Interaction: staffing matters more in non-profit hospitals
    patient_satisfaction = round(
      50 +
      3 * nurse_ratio +                              # Base staffing effect
      5 * (ownership == "Non-Profit") +              # Non-profit baseline higher
      2.5 * nurse_ratio * (ownership == "Non-Profit") + # INTERACTION
      -0.01 * patient_volume +
      -3 * avg_acuity +
      rnorm(n, 0, 5),
      1
    ),
    patient_satisfaction = pmax(0, pmin(patient_satisfaction, 100)),
    ownership = factor(ownership, levels = c("For-Profit", "Non-Profit"))
  )

Variables in the dataset:

  • hospital_id: Unique identifier for each hospital (1 to 300)
  • ownership: Hospital ownership type (For-Profit or Non-Profit)
  • nurse_ratio: Nurse-to-patient ratio (ranging from 2 to 6)
  • patient_volume: Annual patient volume (number of patients)
  • avg_acuity: Average patient acuity level (1 = low, 3 = high complexity)
  • patient_satisfaction: Patient satisfaction score on 0-100 scale (our outcome variable)

3.4.2 Visualizing the Potential Interaction

Before running the model, always visualize to see if an interaction might exist:

3.4.3 Fitting the Interaction Model

When we fit a model with an interaction, we can either use the * symbol between variables or the : symbol between variables with each variable included with the + sign.

# Model WITH interaction 
# Alternative syntax for interaction: nurse_ratio + ownership + nurse_ratio:ownership
model_interact <- lm(patient_satisfaction ~ nurse_ratio * ownership, data = satisfaction_data)
summary(model_interact)

3.5 Categorical × Categorical Interaction

Interactions can also occur between two categorical variables.

3.5.1 Categorical × Categorical Example: Treatment Effect Varies by Insurance Type

3.5.1.1 Background and Context

The context: Diabetes management programs help patients control blood sugar levels (measured by HbA1c). Different programs exist:

  • Standard Care: Regular doctor visits and medication management
  • Intensive Program: Structured education, nutrition counseling, and regular coaching

Question: Does program effectiveness vary by insurance type (Medicare, Medicaid, Private)?

Why it might vary:

  • Access to additional support services differs by insurance
  • Co-pays and out-of-pocket costs vary
  • Transportation and time off work (easier for retirees with Medicare than workers with private insurance)
  • A 2023 study on Medicare Diabetes Prevention Program found significant implementation challenges, with very limited program availability nationwide, suggesting access and effectiveness barriers vary across insurance types.

Let’s test whether an intensive diabetes program works differently for patients with different insurance types. This is a categorical (insurance type) × categorical (program type) interaction.

3.5.1.2 Creating Synthetic Healthcare Data

Let’s create a dataset using the code below:

# Generate data
n <- 400

diabetes_data <- tibble(
  patient_id = 1:n,
  treatment = sample(c("Standard Care", "Intensive Program"), n, replace = TRUE),
  insurance = sample(c("Medicare", "Medicaid", "Private"), n, replace = TRUE,
                    prob = c(0.4, 0.3, 0.3)),
  baseline_a1c = round(rnorm(n, 8.5, 1.2), 1),
  age = round(rnorm(n, 60, 12))
) %>%
  mutate(
    baseline_a1c = pmax(6, pmin(baseline_a1c, 12)),
    age = pmax(30, pmin(age, 85)),
    # Generate A1c reduction with interaction
    a1c_reduction = round(
      0.5 +
      0.3 * (treatment == "Intensive Program") +   # Base treatment effect
      0.2 * (insurance == "Private") +              # Private insurance effect
      0.1 * (insurance == "Medicare") +
      # Interactions: treatment works better with Private insurance
      0.8 * (treatment == "Intensive Program") * (insurance == "Private") +
      0.3 * (treatment == "Intensive Program") * (insurance == "Medicare") +
      0.05 * baseline_a1c +
      rnorm(n, 0, 0.4),
      2
    ),
    a1c_reduction = pmax(0, a1c_reduction)
  )

Variables in the dataset:

  • patient_id: Unique identifier for each patient (1 to 400)
  • treatment: Type of diabetes program (Standard Care or Intensive Program)
  • insurance: Insurance type (Medicare, Medicaid, or Private)
  • baseline_a1c: Baseline HbA1c level before treatment
  • age: Patient age in years
  • a1c_reduction: Reduction in HbA1c after treatment (our outcome variable)

3.6 Continuous × Continuous Interaction

Interactions can also occur between two continuous variables, where the effect of one continuous variable depends on the level of another continuous variable.

3.6.1 Continuous × Continuous Interaction Example: Age Moderates Physical Therapy Effect

3.6.1.1 Background and Context

The context: Physical therapy (PT) is commonly prescribed for musculoskeletal conditions like joint pain, post-surgery recovery, and mobility issues. Patients typically attend multiple sessions over several weeks to improve functional capacity.

Question: Does the benefit of additional PT sessions depend on patient age?

Why it might vary:

  • Tissue healing capacity: Younger patients may have faster tissue repair and adaptation to exercise
  • Baseline strength and conditioning: Younger patients often have better baseline capacity to benefit from therapy
  • Comorbidities: Older patients may have multiple health conditions that limit their response to therapy
  • Adherence to home exercises: Younger working adults may have different adherence patterns than older retirees

The hypothesis: Additional PT sessions might provide greater functional improvement for younger patients compared to older patients due to differences in physiological recovery capacity and treatment response.

  • Physical therapy effectiveness can vary significantly across patient populations, with factors such as age, baseline function, and comorbidities potentially moderating treatment response.

Let’s test whether the effect of PT session count on functional improvement varies by patient age. This is a continuous (PT sessions) × continuous (age) interaction.

3.6.1.2 Creating Synthetic Healthcare Data

Let’s create a dataset using the code below:

# Generate data
n <- 250

pt_data <- tibble(
  patient_id = 1:n,
  pt_sessions = round(runif(n, 4, 24)),
  age = round(runif(n, 25, 80)),
  baseline_function = round(runif(n, 30, 70))
) %>%
  mutate(
    # Interaction: PT sessions more effective for younger patients
    function_improvement = round(
      5 +
      1.2 * pt_sessions +
      -0.1 * age +
      -0.03 * pt_sessions * age +  # Negative interaction
      0.3 * baseline_function +
      rnorm(n, 0, 5),
      1
    ),
    function_improvement = pmax(0, function_improvement)
  )

Variables in the dataset:

  • patient_id: Unique identifier for each patient (1 to 250)
  • pt_sessions: Number of physical therapy sessions attended (4 to 24 sessions)
  • age: Patient age in years
  • baseline_function: Baseline functional capacity score before therapy (higher scores indicate better pre-treatment function)
  • function_improvement: Improvement in functional capacity after therapy in points (our outcome variable)

3.6.2 Fitting the Interaction Model

Let’s fit the model using the lm() function.

# Fit model with interaction
# Alternative expression: pt_sessions + age + pt_sessions:age
model_pt <- lm(function_improvement ~ pt_sessions * age,
               data = pt_data)

    • The negative value means that PT sessions become less effective as age increases
    • For each additional year of age, the benefit of one PT session decreases by 0.0257 points

Computing Marginal Effects at Different Ages:

In interaction models, we’re interested in the marginal effect, the effect of one variable (PT sessions) at specific values of another variable (age). Because of the interaction, this marginal effect changes with age.

The marginal effect of PT sessions at any given age is calculated as:

\[\frac{\partial \text{Improvement}}{\partial \text{PT Sessions}} = \beta_{\text{pt\_sessions}} + \beta_{\text{interaction}} \times \text{Age}\]

Let’s calculate the marginal effect of one additional PT session at different ages:

  • Age 30: Effect = 1.11 + (30 × -0.0257) = 0.34 points per session (positive = beneficial)
  • Age 50: Effect = 1.11 + (50 × -0.0257) = -0.17 points per session (negative = harmful)
  • Age 70: Effect = 1.11 + (70 × -0.0257) = -0.69 points per session (negative = harmful)

The effect of PT sessions changes dramatically with age. For younger patients (age 30), additional PT sessions improve function. However, the effect becomes negative for older patients (ages 50 and 70), meaning additional sessions are associated with worse functional outcomes. This crossover pattern demonstrates how interactions can reverse the direction of an effect.

4 Practical Considerations

4.1 When to Include Interactions

Include interactions when:

  1. Theory or prior research suggests the effect should vary
  2. Visual inspection shows different slopes for different groups
  3. You have sufficient sample size (interactions require larger samples)

4.2 Centering Variables

For models with continuous × continuous interactions, centering variables (subtracting the mean) makes the main effects much more interpretable.

Why centering helps?: In the uncentered PT model, the main effects were at age = 0 and pt_sessions = 0, which are meaningless. After centering, the main effects are at the mean age and mean PT sessions, which is much more interpretable.

Let’s re-fit the PT model with centered variables and compare:

# Center variables by subtracting their means
pt_data <- pt_data %>%
  mutate(
    age_c = age - mean(age), # mean-centering the variable age
    pt_sessions_c = pt_sessions - mean(pt_sessions) # mean-centering the variable pt_sessions
  )

# Check the means of centered variables (should be approximately 0)

6 Summary

6.1 What We Covered in This Lecture

This lecture extended linear regression to handle categorical predictors and situations where effects vary across groups.

6.1.1 1. The Challenge: Including Categories in Regression

The problem: Regression needs numbers, but many important variables are categorical (hospital type, insurance status, treatment group).

The solution: Dummy variables (also called indicator variables)

  • Use 0s and 1s to represent category membership
  • For k categories, create k-1 dummy variables
  • One category serves as the reference (baseline) for comparison

Key concept: Dummy variable coefficients show the difference between each category and the reference category, holding other variables constant.

6.1.2 2. How Dummy Variables Work

Binary categories (two groups):

  • Create ONE dummy variable (0 or 1)
  • Coefficient = difference in outcome between the two groups
  • Example: ERAS protocol vs. Standard care

Multiple categories (three+ groups):

  • Create k-1 dummy variables (one less than number of categories)
  • Each coefficient compares that category to the reference
  • Example: Teaching vs. Community vs. Critical Access hospitals
  • Change reference category with relevel() to make different comparisons

Why k-1 instead of k? Including all categories creates perfect multicollinearity with the intercept.

6.1.3 3. Interaction Effects: When Effects Depend on Context

What are they? An interaction occurs when the effect of one variable changes depending on another variable. In plain language, “it depends!” The answer to “What’s the effect of X on Y?” is “It depends on Z.”

Types of interactions:

  • Continuous × Categorical: Does nurse staffing effect differ by hospital ownership?
  • Categorical × Categorical: Does treatment effectiveness vary by insurance type?
  • Continuous × Continuous: Does PT session benefit depend on patient age?

6.1.4 4. Recognizing Interactions

Visual clue: Different slopes for different groups in your scatter plots

When to test for interactions:

  • Theory suggests effect should vary across groups
  • Plots show different slopes
  • You want to know if an intervention works differently for different populations

6.1.5 5. Interpreting Interactions

The key challenge: Main effects change meaning when interactions are present!

For Continuous × Categorical:

  • Main effect of continuous variable = effect for the reference category only
  • Interaction coefficient = how much that effect changes in other categories
  • To get effect for non-reference categories, add main effect + interaction

Example:

  • Nurse staffing effect in For-Profit hospitals: β = 3.0
  • Interaction (Non-Profit): β = 2.5
  • Nurse staffing effect in Non-Profit hospitals: 3.0 + 2.5 = 5.5

For Categorical × Categorical:

  • Use emmeans() to calculate and compare means for all combinations
  • Visualize with grouped bar charts
  • Each interaction term shows how treatment effects differ across categories

For Continuous × Continuous:

  • Main effects without centering: Represent effects when the other variable = 0 (often meaningless)
  • Main effects with centering: Represent effects at the mean of the other variable (meaningful!)
  • Interaction coefficient: Shows how the slope of one variable changes as the other variable increases
  • Marginal effects (slopes): Calculate the effect of one variable at specific values of the moderator
    • Formula: Slope of X = β_X + (β_interaction × value of Z)
    • Use probe_interaction() or manual calculation to get slopes at different moderator values (and to visualize the interaction)
  • Crossover effects: The effect can even reverse direction (positive → negative) at different moderator values

Example:

  • PT sessions effect at age 30: β_sessions + (β_interaction × 30) = 0.30 (beneficial)
  • PT sessions effect at age 70: β_sessions + (β_interaction × 70) = -0.60 (harmful)
  • The interaction creates a crossover where the effect reverses from beneficial to harmful

6.1.6 6. Practical Considerations

Sample size: Interactions require larger samples because you’re splitting data into subgroups

Centering variables: For models with interactions, center continuous variables (subtract the mean) to make coefficients more interpretable
